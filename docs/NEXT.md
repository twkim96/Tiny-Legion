# 남은 개발

## 우선 확인

- Android 실제 WebView에서 로그인 연결, 저장, 종료·복귀, 터치, 소리, 전체 화면, 물량 전투 성능 확인.
- iOS WKWebView의 같은 항목과 안전 영역 확인.
- 실제 플레이에서 편성·소환 순서가 방치 생존과 수익을 충분히 바꾸는지 확인.
- 도전과 속공에서 같은 최적 편성이 반복되지 않는지 확인.
- 모집·레벨 비용·다이아 공급과 첫날 성장 속도 조정. 모바일에서 모집 후 강화와 재전투 흐름 확인.

## 다음 구현

- Sites D1 서버 계정 저장과 재화 변경, 기록 검증, 날짜·원자적 보상 처리. 기기 간 연결과 인증 경로 검증.
- 진행 중 전투 저장·복구 여부와 전투 재현 기록 정책 확정.
- 동료 11종 이상 또는 검증 데이터로 상위 10명 레벨 동기화 구현·검증. 현재 동료 5종에는 이 정책을 임의 축소 적용하지 않습니다.
- 진화·독립 잠재능력, 같은 보석 강화, 슬롯 각인, 프리셋, 5슬롯 단계 개방.
- 성 방어병력과 전투 스킬 성장. 현재 수동 전투에는 기본 대포만 있습니다.
- 지역 추가와 스테이지별 패턴·공간·적 능력의 실제 차별화.
- 속공 날짜 경계 미수령 처리·점수 곡선·골드/다이아별 최적 기록 정책의 최종 승인.
- 계정/편성 전투력은 전투 시뮬레이션 결과와 분리한 참고 지표로 추가.

브라우저 검증은 실제 휴대폰과 WebView 수용 테스트를 대체하지 않습니다. 최초 배포는 기획 검증용으로 비공개 유지합니다.
