# 미완료 작업

현재 구현은 [SPEC](SPEC.md), 확정 확장 계약은 [확장 설계](SPEC/expansion.md)를 따릅니다. 아래는 기존 개발 목록과 v0.3 기획에서 남은 구현·결정·수용 검증입니다. 문서 초기화가 제품 구현·배포 승인을 대신하지 않습니다.

## 우선 수용 검증

- 신규 1-2 튼튼한 성 시간 초과 → 숲속 무료 1회 속공 토끼 확정 → 같은 성 재도전 승리 → 1-2 방치 실패 → 토끼 교체/비우기/적용 → 방치 생존 → 레벨업 해금·미션·첫 성장 흐름을 PC·667×375·844×390·932×430에서 확인합니다. 느린 소환·대포·순서 변경, 안내 중 재접속·불러오기, 팝업 중 방치 지속, 지급·미션 중복 방지와 기존 성장 계정 이주를 확인합니다. 자동 전투와 계정 회귀 검증은 실제 플레이 난이도 승인·WebView 수용 검증과 구분합니다.

- 같은 배포 주소를 여러 탭에서 열었을 때 진행도 저장 충돌을 방지해야 합니다. 현재 각 탭이 독립된 계정 스냅샷을 주기적으로 저장하므로 이전 버전 탭이 새 진행도를 덮어쓸 수 있습니다. 새 버전의 미션·기록·재화가 새로고침 후 되돌아가는 상황을 재현했고, 한 탭만 사용하는 임시 안내와 자동 테스트의 단일 저장소 검증을 구분합니다. 저장 동기화 또는 단일 저장 주체를 구현한 뒤 성장·미션 수령·불러오기·초기화·이전 버전 탭 공존을 확인해야 합니다.

- 반투명 자동 표시가 방치의 보유 슬롯에서만 회전하는지, 일반 숲속 배너의 1회 무료→씨앗 다람쥐 확정→재도전, 첫 방치 미션→도전 1-2 미션·직접 진입·추가 보상 수령, 방치 완료/실패 결과창이 열린 채 자동 재시작·생산되는지, 스테이지별 숨김·재접속·설정에서 다시 표시, 오른쪽 아래 전투 시작·오른쪽 메뉴의 속공/보석/설정 진입과 잠금, 수동 결과의 방치 복귀를 PC·667×375·844×390·932×430에서 확인합니다. 기존 계정 미션 이주·중복 보상·팝업 비정지는 자동 검사하며 실제 UI·길게 누르기·안전 영역 수용 검증은 별도입니다. localhost는 저장된 권한 설정으로 차단됩니다.

- 고정 5열 × 2행 소환창의 빈 슬롯·첫 동료·두 번째 동료·전체 편성을 PC·모바일 가로에서 확인합니다. 카드 너비 유지·초상화 중심·소환 격자 왼쪽의 큰 전투 골드/오른쪽의 큰 대포/순서 버튼 겹침, 격자 바로 위 고정 설명의 양쪽 행·카드 이동 시 위치와 긴 설명 가독성·카드 미겹침·500ms 길게 누른 뒤 소환 방지, 1–9·0 소환, 빈 칸 건너뛰기와 편성 비우기·재접속 위치 보존을 확인해야 합니다. 저장·전투 자동 검증과 실제 화면 검증을 구분합니다.

- 설정의 계정 초기화에서 취소·확인·0스테이지 재시작과 새로고침 후 유지, 사전 내보내기/불러오기 복구, 저장 실패 시 기존 진행도 보존을 PC·모바일에서 확인합니다. 첫 안내 중 전투에서도 메뉴 안 설정에 접근할 수 있어야 합니다. 실제 화면 검증은 브라우저 접근 제한으로 미완료입니다.
- 신규 계정의 양 방패만 보유 → 0스테이지 소환·승리 → 1-1 실패 → 다람쥐 무료 확정 공개 → 두 동료 재도전·승리 → 방치 안내·1-1 자동 전투를 PC·모바일 가로 화면에서 확인합니다. 안내 중 메뉴 제한·키보드·모달 포커스, 각 단계 새로고침/불러오기, 지급 직후 재접속·중복 방지, 기존 계정 진행 보존과 소환을 늦게 한 초보자의 재도전 난이도를 확인해야 합니다. 계정·전투 자동 검증과 실제 화면 수용 검증을 구분합니다.
- 진해진 하늘과 약한 상단 그라데이션 위 그림자·외곽선 없는 재화·스테이지 글자, 기존 상단 메뉴 아이콘과 중앙 정렬한 흰색 사각 소환 카드를 PC와 667×375·844×390·932×430 브라우저에서 확인합니다. 메뉴창 열기·닫기, 수동 전투 중 일시 정지·배속·메뉴 순서의 상단과 준비/결과 메뉴 복귀, 상단 일시 정지·계속과 Space의 같은 상태 전환, 설정에서 소리 전환, 도토리와 전투 동전 구분·강화/생산/완료 보상의 일관된 재화 표시, 저장된 2×에서 방치 1× 전환, 전투 모드 전환과 속공 잠금, 준비/결과 화면의 메뉴 접근, 카드 줄 중심·별도 전투 골드·순서 버튼·대포 사이의 겹침, 카드 안 초상화의 가로·세로 중심과 가격 여백, 쿨타임·자동 소환 차례 구분, 왼쪽 위 전투력·각 성 위 체력 수치와 막대의 위치 및 화면 크기 변경 시 성과의 정렬, 밝은 맵 위 글자 대비 및 안전 영역이 확인되어야 합니다. 현재 저장된 브라우저 권한 설정이 localhost 접근을 차단하므로 실제 화면 검증은 미완료입니다. 코드 검사와 자동 테스트는 실제 화면 검증을 대신하지 않습니다.
- 공격 준비·타격·복귀, 아군/적군 투사체의 비행·착탄, 피격 경직을 같은 가로 화면 크기에서 확인합니다. 정지/재개·2×·저프레임·재전투 시 모션과 피해 시점이 맞아야 하며, 다수 유닛 전투에서 효과 가독성과 프레임 성능을 확인해야 합니다. 바뀐 타격 시간에 따른 생존·생산·클리어 시간의 밸런스는 실제 플레이로 승인합니다.
- Android 실제 WebView에서 Sites 로그인 연결, 저장·파일 이동, 종료·복귀, 터치·긴 누르기, 소리, 전체 화면, 다수 유닛 성능을 확인합니다. 실제 기기에서 진행도 보존과 플레이 흐름을 재현하고 제한을 기록하면 완료입니다. 게임 서버 로그인은 서버 작업 이후 확인합니다.
- iOS WKWebView에서 같은 항목과 안전 영역을 확인합니다. 실제 기기에서 화면 잘림·저장 유실·입력 오작동 여부를 확인해야 합니다.
- 실제 플레이에서 편성·순서가 방치 생존·수익을 의미 있게 바꾸는지, 30초 실패 반복이 120초 생존보다 유리하지 않은지, 하위 스테이지가 더 나은 생산처가 될 수 있는지 확인합니다. 모드별로 다른 최적 편성·보석이 유효한 플레이 결과를 남깁니다.
- 첫 웨이브가 적 성 앞에서 출발하는 변경 뒤 초반 대기·교전 시간과 방치 생존·생산, 도전·속공 기록을 실제 플레이로 확인합니다. 자동 검증으로 생성 위치와 이동 방향을 확인했으며, 이전 생산 기록은 당시 결과로 유지합니다.
- 모집·레벨 비용·다이아 공급·첫날 성장 속도를 조정합니다. 모바일에서 모집→강화→재전투 흐름과 다수 유닛의 역할·동작 가독성을 확인해 초기 밸런스를 승인합니다.
- 3~5배로 올린 소환 비용을 실제 플레이로 확인합니다. 초반 첫 소환 대기, 비싼 동료 차례의 대기와 전선 유지, 높은 레벨에서의 유닛 누적, 도전·속공 클리어 시간을 확인해야 합니다. 자동 전투 수량 비교는 전체 스테이지·편성 밸런스 승인을 대신하지 않습니다.

## 동료 모집·도감 수용 검증

- 속성 포인트 색(야생 초록·기계 은색·정령 하늘·그림자 보라), 같은 적의 웨이브 속성 변경, 괄호 색 이름 없이 색상 볼드로 표시한 특화 설명·적 외곽선, 1지역 단일 속성→2지역 혼합과 모집 잠금/개방을 PC·모바일 가로에서 확인합니다. 숲속 모집 6종·영웅 12%·공방/별빛의 선택 풀·무료 10회 1회 한도·공유 보장·다시 모집·기존 계정의 잠긴 편성 보존/2-1 복귀를 확인하고, 1지역의 쉬운 성장 흐름과 2지역 난이도를 실제 플레이로 승인합니다. 자동 테스트와 실제 화면 수용 검증은 구분합니다.

- 15종의 초상화·전투 스프라이트, 모집 1회/10회·무료 모집·영웅/전설 공개 색감·직접 열기·모두 보기·다시 열기·도감 이동, 보유/희귀도 필터와 10칸 편성을 PC와 목표 모바일 가로 크기에서 확인합니다. 저장된 브라우저 권한 설정이 localhost 접근을 차단해 실제 화면 검증은 미완료입니다. 자동 지급·저장 호환·미보유 소환 제한 검증과 구분합니다.
- 새 10종의 역할·속성별 소환 비용·화력·생존·회복과 기본 모집 확률·보장·10회 할인·무료 10회·다이아 수급을 플레이로 조정합니다. 기존 동료의 쓰임과 무작위 획득 뒤 편성 변화가 유효한지 확인하면 초기 밸런스 승인입니다.

## 캐릭터 외형 수용 검증

- 야생·기계·정령·그림자 동료의 몸체·재질·실루엣과 태닝한 야생 동물 적군을 PC·목표 모바일 가로 크기의 실제 전투·도감·모집에서 확인합니다. 아군과 적군이 작은 크기에서 구분되고, 원거리 적의 탄과 신규 실루엣이 기존 공격 자세에 맞아야 합니다. SVG 원화 렌더링 확인은 실제 게임 화면 수용 검증을 대신하지 않습니다. 저장된 localhost 브라우저 권한 제한은 유지됩니다.

## 속성·기믹 수용 검증과 확장

- 역할별 20~40% 특화, 유효 체력 계산, 구름 방어막 지원·둔화·재생 억제를 실제 플레이로 조정합니다. 씨앗 다람쥐 중심 숲속 편성과 다른 배너의 대응 편성을 같은 성장 수준에서 비교하고, 특정 동료 없이 성장으로 도전·속공을 돌파할 수 있는지 확인합니다. 전체 스테이지와 모드의 밸런스 승인은 자동 회귀 검증과 구분합니다.
- 도감·스테이지 속성 구성/웨이브 설명과 방어막 테두리·재생/방해 표식을 PC·모바일 가로 화면에서 확인합니다. 4속성·후반 증원에 따른 소환 순서 선택이 읽히고 전투 화면이 복잡해지지 않아야 합니다. 브라우저 권한 제한과 실제 WebView 미검증은 유지합니다.
- 역할별 잠재능력·진화·특화 각인을 성장 확장과 함께 구현합니다. 새 능력 비용·해금·상한을 정한 뒤 가산 보너스와 기록 스냅샷 보존을 검증합니다. 현재 역할 계산 지원을 해당 성장 메뉴 구현 완료로 취급하지 않습니다.
- 광폭화·돌진·광역 공격·상태이상·장갑·소환 후보의 우선순위·대체 해법을 정하고, 주요 적·보스부터 구현합니다. 현재 방어막·재생 도입은 나머지 기믹 구현 완료가 아닙니다.

## 계정과 전투 데이터

- Sites D1 서버 계정 저장·재화 변경·기록 검증·서버 날짜·원자적 일일 보상을 설계하고 구현합니다. 공용 인증·기기 연결을 검증하며 동시 클릭·네트워크 재시도·강제 종료에서도 중복 지급과 진행도 유실이 없어야 합니다. 엔드포인트와 마이그레이션·복구 안내를 구현 이후 문서화합니다.
- 진행 중 전투 저장·복구 여부와 전투 재현 기록 정책을 결정합니다. 종료·복귀·새로고침의 결과, 저장 형식과 밸런스 버전 호환성을 명시하고 선택한 정책으로 검증합니다.
- 방치의 비선형 보상 산식, 120초 기준 정산, 골드·다이아 곡선·소수점·상한, 별도 최고 기록 선택, 오프라인 한도·기록 영구 유지 여부를 최종 승인합니다. 성장·보석·각인·버전 변경의 재검증 범위를 정하고 이전 기록에 무검증 보너스가 합성되지 않게 검증합니다. 현재 한 스테이지 생산·8시간 한도·골드 최고 기록은 초기 정책입니다.
- 속공 날짜 경계·미수령 이월/자동 수령 여부·최고 기록 수령, 시간→점수→보상 곡선과 보상 상한·모집 환산을 최종 승인합니다. 현재 Seoul 자정·미수령 초기화 정책을 결정과 구분하며 날짜를 넘는 전투·수령 직전 경계를 검증합니다. 스테이지 교체·웨이브·시간 제한·스킬 허용도 결정합니다. 기존 개발 목록의 “골드/다이아별 최적 기록”이 방치 기록 선택을 뜻하는지 속공 보상 분기를 뜻하는지도 명확히 합니다.

## 성장과 콘텐츠 확장

- 15종 로스터에서 상위 10명 일반 레벨 동기화를 구현·검증합니다. 직접 투자만으로 자동 선정하고 동기화 레벨을 재선정에 넣지 않아야 합니다. 10명 미만·동률·미보유 규칙을 결정하며 미보유 동료에 대한 정책을 임의 적용하지 않습니다.
- 일반 레벨 최종 상한·진화 요구 레벨, 진화 단계·재료·형태 선택, 진화와 독립적인 잠재능력을 결정·구현합니다. 특별강화·잠재능력 재화·상한·수급·초기화, 개별 일반 레벨 초기화·환급·균등 강화 여부도 정하고 도전 진행 기반 해금과 함께 검증합니다. 원본 해금표의 번호는 예시입니다.
- 동일 보석+골드 강화, 슬롯 랜덤 각인, 프리셋, 최대 5슬롯의 단계 개방을 구현합니다. 각인 확률·등급·비용·이전 옵션 보존, 프리셋의 각인 공유/별도 세트·자동 적용·중복 장착, 보석 모집 확률·천장·중복 처리·가격을 결정합니다. 보석 교체 후 슬롯 각인과 검증 방치 기록이 보존되어야 합니다.
- 성 방어병력과 전투 스킬 성장을 구현합니다. 시설·배치 수·사거리·모드 제한과 스킬 수·쿨타임·자원·강화 상한을 정하고 일반 동료·방치 전용 지원·수동 스킬의 역할 경계를 검증합니다. 현재 수동 전투의 기본 대포는 이 작업의 완료가 아닙니다.
- 지역마다 10스테이지를 유지하며 지역·적·공간·웨이브와 전술 역할을 확장합니다. 원본 캐릭터 후보는 확정 명단으로 취급하지 않고 실제 플레이에서 패턴과 대체 편성의 차이를 확인합니다.
- 계정 전투력은 체력·초당 공격력 기반 참고 수치로 표시합니다. 사거리·광역·회복·시너지의 역할 가중치와 상한, 실제 전투 결과와의 관계를 결정·검증합니다. 현재 계정 전투력의 범위는 [성장 사양](SPEC/account.md#전투력)을 따릅니다.

브라우저나 자동 테스트의 통과는 실제 휴대폰·WebView 수용 검증을 대체하지 않습니다. 최초 배포의 비공개 운영 방침은 [호스팅 안내](operations/storage-and-hosting.md)에 있습니다.
