# 디자인과 동작 정책

## 화면

- 모바일 가로 화면 우선. 667×375, 844×390, 932×430 및 PC 가로 화면을 목표로 합니다.
- 세로 휴대폰 화면에는 회전 안내를 표시하고 진행 중 전투 계산을 멈춥니다. 기록 기반 생산은 계속 정산됩니다.
- 위에서 재화, 전투 선택, 전장, 소환 카드, 메뉴 순서. 모바일 가로에서는 전체가 한 화면에 들어옵니다.
- PC에서는 같은 구성을 최대 1360px의 패널로 표시합니다. 전투 공간을 웹 랜딩 페이지로 바꾸지 않습니다.
- 아이보리 `#faf8ef`, 먹색 `#35372e`, 세이지 `#657950`, 약한 금색과 흙색 포인트. 그림은 제한된 색상과 부드러운 윤곽선을 사용합니다.
- 화면 이름은 방치·도전·속공·동료·모집·도감. 홍보 부제, 설명 카드와 메타 용어를 상시 배치하지 않습니다.
- 수치 설명은 PC hover / 키보드 접근 가능한 도감 / 모바일 500ms 길게 누르기에 배치합니다.
- 모달은 키보드 포커스를 가두고, 닫으면 이전 버튼으로 돌아갑니다. 모든 아이콘 버튼에 접근성 이름을 둡니다.

## 캐릭터

직접 작성한 SVG는 UI 초상화와 Canvas 애니메이션에 같이 사용합니다. 원본은 `dist/src/art.js`의 `figures`이며 비트맵 의존성은 없습니다.

| 동료 | 실루엣과 소품 | 역할 |
|---|---|---|
| 양 방패 | 둥근 흰 털, 세이지 얼굴, 앞의 큰 방패 | 저비용 앞줄 방어 |
| 목검 토끼 | 긴 귀, 짧은 흙색 목도리, 나무 검 | 빠른 접근과 연속 공격 |
| 씨앗 다람쥐 | 큰 말린 꼬리, 씨앗 새총 | 장거리 공격 |
| 주전자 | 둥근 몸통, 손잡이, 주둥이 | 범위 공격 |
| 구름 | 부드러운 구름 외곽, 작은 번개 | 장거리 공격과 근처 동료 회복 |

- 적: 작은 딱정벌레, 납작한 버섯 모자, 둥근 멧돼지. 적 방향을 반전하여 전선 방향이 보이게 합니다.
- 128×120 SVG 좌표 기준 윤곽선 약 3.2px. 점눈, 짧은 입, 작은 소품. 역할별 강한 원색은 사용하지 않습니다.
- 걷기는 짧은 몸 기울기와 상하 움직임, 구름은 떠다니는 움직임. 공격 준비/타격, 피격 투명도, 짧은 씨앗·타격 효과를 표시합니다.
- 다수 유닛은 작은 깊이 차이로 겹침을 구분합니다. 피격 유닛에만 작은 체력 막대를 표시합니다.

## 초기 구현 정책

아래 수치는 초기 검증용이며 원본 기획의 예시를 최종 확정한 것으로 취급하지 않습니다.

- 시작 자원: 골드 600, 다이아 60. 기본 동료 5종 제공. 모집은 동료 조각을 줍니다.
- 방치는 골드 검사 후 쿨타임 검사. 골드 부족 시 현재 항목을 기다립니다. 중복 항목은 같은 쿨타임을 공유합니다.
- 소환 순서 편집은 적용 시 새 전투부터 시작합니다. 도전·속공은 키보드 1–5 또는 소환 카드로 조작합니다.
- 전투 계산은 1/30초 단위. 속도 2×는 전투 시간도 2×로 흐르며 속공 기록은 시뮬레이션 시간입니다.
- 도전·속공 모달을 열거나 탭이 숨겨지면 현재 전투 계산을 멈춥니다. 방치 기록 기반 생산은 전투와 독립적입니다. 측정 도중 새로고침하면 해당 전투는 다시 시작합니다.
- 방치 기록은 당시 레벨·특별강화·순서·보석을 저장합니다. 이전 기록에 새 보너스를 합성하지 않습니다. 측정 전투 자체의 보상을 생산 정산과 중복 지급하지 않습니다.
- 일반 레벨과 특별강화 상승, 보석 변경은 다음 전투에 적용합니다. 편성 교체는 기존 기록을 보존합니다. 일반 레벨 초기화는 기존 기록을 무효화하며 재검증이 필요합니다.
- 방치 기록별 더 높은 골드 성적을 보존하고 선택한 한 스테이지에서만 생산합니다. 처음에는 측정 완료 전 생산 기록이 없습니다.
- 속공은 1-3 이후 개방하고 동일한 1-1을 사용합니다. 하루 기준은 Asia/Seoul 00:00. 미수령 보상은 다음 날 초기화됩니다. 날짜가 바뀌는 전투는 새 날 보상 기록으로 넘기지 않습니다.
- 속공 최고 기록을 수동 수령하고 보석 조각을 지급합니다. 수령 후 기록은 연습용이며 추가 보상은 없습니다.
- 보석 3종: 공격 +10%, 체력 +15%, 검증 방치 골드 +15%. 1슬롯, 자유 교체. 보석 조각 5개 또는 다이아 30으로 모집합니다.
- 보석 슬롯 각인과 동일 보석 강화는 다음 개발에 남깁니다.
- 지역당 10스테이지를 유지하되 현재는 한 지역만 제작했습니다. 웨이브와 스탯은 플레이테스트 대상입니다.

## 모바일 확장

전투 엔진·게임 데이터·SVG 리소스를 UI와 분리합니다. 이후 Capacitor 앱에서 재사용할 수 있도록 게임 화면에 서버 전용 렌더링을 요구하지 않습니다. 계정 저장은 현재 기기 내 파일이며, 모바일 공용 서버 인증과 API는 별도로 설계·검증해야 합니다.
