# 화면과 아트

## 화면

- 모바일 가로 화면 우선. 667×375, 844×390, 932×430 및 PC 가로 화면을 목표로 합니다.
- 세로 휴대폰 화면에는 회전 안내와 `전체 화면` 버튼을 표시합니다. 클릭 직후 문서 전체화면을 요청하고, 성공하면 지원 브라우저에서 가로 방향 고정을 시도합니다. 전체화면에서 나가면 방향 고정을 해제합니다. 가로 고정이 불가능하면 전체화면을 유지하고 직접 회전·회전 잠금 해제를 안내하며, 전체화면 미지원/거절도 같은 안내 영역에 표시합니다. 설정의 전체화면 진입도 같은 함수를 사용합니다. 버튼은 서버 로그인 완료 전에도 작동합니다. 구현은 `dist/src/fullscreen.js`가 관리하고 전투·생산의 시간 규칙은 [전투](battle.md)를 따릅니다.
- 전장이 게임 화면 전체를 채웁니다. 그 위에 좌측 상단 동료 초상화·재화·전투력, 상단 중앙 스테이지·시간·상태, 우측 상단 메뉴 아이콘, 하단 소환 카드·전투 골드·대포를 겹쳐 표시합니다. 별도의 상하단 내비게이션 바는 없습니다.
- 방치와 준비·결과 화면에서는 동료·모집·도감·메뉴 아이콘을 제공합니다. 기존 전투·설정 진입 아이콘은 제거하고 설정은 메뉴 안에서 엽니다. 방치의 오른쪽 아래 `전투 시작`으로 다음 도전 스테이지를 바로 시작합니다. 도전·속공 진행 중 상단은 순서·나가기·일시 정지·1×/2×·메뉴를 제공하며 다른 콘텐츠 아이콘은 숨깁니다. 전투 중 메뉴에는 설정만 표시합니다. 모드 표시는 정보만 제공합니다. 메뉴는 오른쪽에서 열리는 어두운 패널 안에 미션·동료·모집·도감·방치·속공·보석·순서·설정 아이콘을 나열합니다. 속공·보석은 2-1 완료 전 잠기며 이후 추가 콘텐츠도 이 메뉴로 진입합니다. 수동 전투에서 메뉴·설정을 열면 전투가 정지하고, 방치에서는 계속 진행합니다. 도전 성공 결과는 `방치로`와 다음 스테이지 번호의 `도전` 두 버튼을 표시하며 성공 뒤 재도전은 제공하지 않습니다. 마지막 스테이지는 `방치로`만 표시합니다. 실패에는 다시 도전을 유지합니다. 속공은 목표 미달 완료·실패에 재도전을 제공하며, 목표 달성 시 다음 속공으로 진행할 수 있습니다. 속공 목록에서는 이미 수령한 스테이지도 연습할 수 있습니다. 성장 해금 뒤 도전 실패에는 동료·모집 바로가기를 제공하고, 완료했지만 아직 받지 않은 미션이 있으면 미션 보상 버튼도 표시합니다. 이 버튼은 해당 미션 ID의 보상을 한 번 지급하며 실패 자체에 추가 보상을 주지 않습니다. 1-2 성공의 `방치로`는 1-2 방치로 진입하며, 1-2 방치 안내가 끝나기 전에 `1-3 도전`을 누르면 미션 완료 알림을 띄우고 결과 화면을 유지합니다.
- 모바일 가로·전체화면에서는 좌우 여백 없이 전장이 화면 전체를 채웁니다. 배경과 UI 배치는 화면 너비에 맞춰 펼치고, 캐릭터·성·아이콘의 비율은 유지합니다. 좌우 HUD는 안전 영역 안쪽에 배치하고 소환 격자는 중앙에 둡니다. PC 일반 창에서는 같은 전장과 메뉴 구성을 최대 1600px의 16:9 패널로 표시하며, 작은 가로 화면에는 밀도를 줄인 구성을 적용합니다. 소환 카드는 5×2 배치를 유지하면서 정사각형을 사용하고, 격자 너비는 화면 높이에 따른 카드 크기로 제한합니다.
- 전장 위 재화·스테이지·시간·조작 UI는 테두리 없이 아이콘·초상화·짧은 글자로 표시합니다. 상단 전장에 아래로 사라지는 약한 어두운 그라데이션을 겹치고, 흰색 글자의 크기·굵기로 밝은 맵 위 가독성을 확보합니다. 글자에는 그림자와 외곽선을 사용하지 않습니다. 상단 메뉴는 기존 파스텔 색상과 둥근 사각 아이콘 버튼을 사용하며, 버튼 아래 짧은 이름을 표시합니다.
- 하단 중앙 소환창은 고정 10칸을 5열 × 2행으로 나열하며, 카드 격자의 중심을 화면 중앙에 맞춥니다. 동료 수와 관계없이 카드 너비를 유지합니다. 첫 안내는 양 방패 1칸과 빈 슬롯 9칸, 다람쥐 획득 뒤 동료 2칸과 빈 슬롯 8칸을 표시합니다. 빈 슬롯은 옅은 흰색 카드로 표시하며 소환할 수 없습니다. 키보드 번호도 화면에 표시한 순서를 따릅니다. 흰색 사각 카드와 얇은 먹색 테두리 안에 기존 동료 초상화를 카드 가로·세로 중심에 고정하고, 오른쪽 아래에는 소환 가격을 둡니다. 초상화와 가격이 겹치지 않도록 초상화 크기에 여백을 둡니다. 순서 버튼은 상단 도감 왼쪽에 두며 수동 전투에서도 표시합니다. 순서 적용은 진행 중인 수동 전투를 초기화하지 않고 다음 전투부터 반영합니다. 이름·설명은 hover·길게 누르기로 확인합니다. 방치의 보유 동료 슬롯에는 반투명한 회전 화살표와 `자동` 표시를 겹칩니다. 빈 슬롯·수동 전투에는 표시하지 않고 동작 줄이기에서는 회전을 멈춥니다. 자동 소환 차례는 세이지 테두리, 쿨타임은 어두운 채움과 남은 초, 골드 부족은 흐린 초상화·가격으로 구분합니다.
- 상단 중앙에는 지역·스테이지 번호와 모드·시간을 표시합니다. 계정 재화는 좌측 초상화 옆에 도토리·다이아 아이콘과 숫자로 나열합니다. 도토리는 갈색 갓·황갈색 열매·작은 잎의 SVG 아이콘으로 표시하고, 강화 비용·방치 수익·완료 보상·환급·복귀 안내에도 같은 이름과 아이콘을 사용합니다. 전투 골드는 소환 격자의 왼쪽 바깥에서 세로 중앙을 맞춰 큰 숫자와 동전 아이콘으로 표시합니다. 소환 격자의 오른쪽 바깥에는 커진 대포 버튼을 두고 같은 중앙선을 사용합니다. 방치에서는 사용할 수 없는 대포를 숨깁니다. 좌측 상단에는 검 아이콘과 [계정 전투력](account.md#전투력)을 표시합니다. 아군·적 성 체력은 각 성의 깃발 바로 위 중앙에 남은 체력 / 최대 체력과 막대로 표시하며, 전장 크기가 바뀌면 성 좌표에 맞춰 이동합니다. 방치의 1–3 웨이브 표시는 상단 중앙에 둡니다. 전투 골드 막대도 유지합니다.
- 메뉴창은 기존 아이보리·세이지 구성을 사용합니다. 산·전선 배치는 유지하며, 산 뒤 하늘은 차분한 청록색에서 연한 녹색으로 이어지는 그라데이션을 사용합니다.
- 화면 이름은 방치·도전·속공·동료·모집·도감. 홍보 부제, 설명 카드와 메타 용어를 상시 배치하지 않습니다.
- 수치 설명은 PC hover / 키보드 접근 가능한 도감 / 모바일 500ms 길게 누르기에 배치합니다.
- 특화 설명은 `야생특화`처럼 짧게 쓰고 글자 자체를 해당 속성의 색과 볼드로 표시합니다. 색 이름 괄호는 붙이지 않습니다. 카드 hover·긴 누르기의 설명, 동료 도감·모집 배너에 같은 표기를 사용하며, 적 도감·스테이지 구성의 속성 이름도 해당 색의 볼드로 표시합니다. 적군의 태닝한 털과 종별 실루엣은 유지하며 옷·장비·망토는 실제 속성의 포인트 색으로 통일하고, 몸체 외곽선도 같은 속성의 진한 색으로 표시합니다. 같은 종류의 적이라도 웨이브 속성 지정에 따라 색과 테두리를 바꿉니다.
- 동료 소환 카드의 hover·길게 누르기 설명은 5×2 소환 격자 바로 위의 고정 영역에 표시합니다. 어느 카드·행을 선택하든 격자와 같은 너비·중앙선을 사용하며 포인터 위치를 따라다니거나 카드를 덮지 않습니다. 아이보리 배경과 진한 글자로 표시하며 그림자·글자 외곽선은 사용하지 않습니다. 도감 상세와 함께 속성 특화, 역할별 보너스, 특수 효과를 설명합니다. 일반 동료는 속성 보너스와 불이익이 없고, 특화 동료도 지정 속성 밖에서는 페널티가 없습니다. 방어 보너스는 표시 체력 증가가 아닌 유효 체력으로 설명합니다.
- 적 도감 상세는 속성과 실제 특수기믹을 표시하며 대응 동료 목록은 표시하지 않습니다. 특수효과·버프·디버프는 공통 키워드를 굵은 제목으로 표시하고 아래에 종족·속성 대상 조건과 범위·주기 등의 수치를 표시합니다. 동료 상세와 도감은 자신의 종족·속성을 대응 특화와 별도로 표시합니다. 효과 용어·수치 설명은 [공통 효과 정의](characters.md#전투-효과)를 따릅니다.
- 스테이지 선택 카드의 정보 버튼을 누르면 웨이브의 적 무리 수를 기준으로 속성 비율을 계산하고, 각 적 무리의 속성·방어막·재생 효과를 현재 모드 제한 시간의 3분할 구간인 초반·중반·후반으로 나누어 표시합니다. 웨이브 그룹의 `attribute`와 `effects`는 적 기본값을 종류별 대체하며, `effects: { shield: false, regeneration: false }`는 해당 효과만 끕니다.
- 전장에서는 방어막이 남은 적에게 얇은 방어막 윤곽과 방어막 체력 막대를 표시합니다. 재생·둔화·회복 억제·중독은 작은 상태 표식으로 구분합니다. 적 변형은 고유 ID의 그림을 먼저 사용하고, `artId`의 기본 자세와 크기를 이어 사용합니다.
- 일반 모달은 키보드 포커스를 가두고, 닫으면 이전 버튼으로 돌아갑니다. 첫 안내 모달은 다음 행동 버튼으로 진행하며 닫기·배경 클릭·Esc로 건너뛰지 않습니다. 확정 모집 결과에는 일반 재모집·도감 이동을 제공하지 않습니다. 첫 안내 종료 전에는 전투·성장·모집·방치·편성 메뉴와 대포를 잠그고 메뉴 안 설정과 상단 나가기·배속·일시 정지 버튼과 키보드 일시 정지는 유지합니다. 소리는 메뉴 안 설정에서 조절합니다. 모든 아이콘 버튼에 접근성 이름을 둡니다.

## 공통 모달

- `openModal(제목, 종류, 렌더)`는 종류에 맞는 공통 크기를 자동으로 적용합니다. 짧은 해금 알림은 최대 320×240px, 안내·확인은 최대 440×400px, 설정·편성·스테이지·수익·속공·확률은 최대 640×560px, 동료·모집·도감·동료 선택은 최대 800×640px를 사용합니다. 메뉴는 오른쪽 서랍 형태로 최대 280px, 화면 너비의 42%와 높이의 70% 이내의 폭을 사용합니다. 메뉴의 닫기 버튼은 40px이며 밝은 배경에 짙은 아이콘을 표시하고 상단·오른쪽 안전 영역을 고려합니다. 콘텐츠가 짧으면 높이는 내용에 맞추고, 화면과 안전 영역보다 커지지 않도록 제한합니다.
- 안내·확인의 본문과 행동 버튼은 `messagePanel`을 공유합니다. 안내 초상화는 96px 영역에 고정하고, 높이 560px 이하 가로 화면에서는 72px 초상화와 설명을 나란히 놓습니다. 제목·뒤로가기·닫기는 고정하고 긴 본문만 안에서 스크롤합니다. 도전 결과는 최대 420px 너비의 작은 카드로 표시합니다.
- 종류와 크기가 다른 흐름만 네 번째 인수로 `{ layout: "collection" }`처럼 지정합니다. 첫 확정 모집은 닫을 수 없는 `onboarding` 동작을 유지하면서 일반 모집과 같은 넓은 크기를 사용하며, 다음 안내에서는 작은 크기로 돌아갑니다. 종류별 기본값은 `dist/src/modal-ui.js`에서 관리합니다.

- 상세·선택·확인 화면은 이전 화면을 모달 스택에 보관하고 제목 왼쪽 뒤로가기 또는 Esc로 한 단계 돌아갑니다. 목록 스크롤·선택 필터·편성 초안을 유지하며 현재 계정 상태로 다시 표시합니다. 닫기와 배경 클릭은 전체 스택을 닫고 처음 모달을 연 버튼으로 초점을 돌립니다. 도감 상세의 동료 전환은 같은 깊이를 교체하며, 강화 재료로 소멸한 보석의 상세/확인은 이력에서 제거합니다. 뒤로가기로 모집·강화·초기화·추가옵션 재설정을 재실행하지 않습니다. 필수 첫 안내는 뒤로가기/닫기로 건너뛸 수 없습니다.

- 레벨업 해금 알림의 `확인`은 동료창을 바로 열며 방치 전투는 계속 진행합니다. 동료 목록에는 `자세히`·`초기화` 버튼을 표시하지 않고 동료 카드 자체를 눌러 성장 상세를 엽니다. 상세에 현재 스펙, 기본 특수 효과, 적용 중인 강화, 추가 강화 옵션과 재료/가격을 함께 표시합니다. 레벨 초기화는 상세 안에서 한 명씩 실행하며 환급할 실제 투자 도토리가 없으면 비활성화합니다. 공유 레벨·기준 다섯 명은 [계정 성장](account.md#현재-성장경제)을 따릅니다. 전체 초기화 버튼은 제공하지 않습니다. 확인창에서 동료·환급 도토리를 확인하고 취소하거나 적용하며 적용·취소 뒤 해당 동료 상세로 돌아옵니다. 상세의 배치·강화 계약은 [동료 특수능력](abilities.md)을 따릅니다. 설정의 테스트용 계정 초기화와는 별도 기능입니다.

## 미션과 방치 결과

- 좌측 상단 캐릭터·전투력 아래에는 현재 미션의 제목, 진행도, 도토리·다이아 보상을 표시합니다. 첫 1-1 승리와 방치 안내 뒤 `1-1 방치 클리어`가 나오고, 수령 후에는 `도전 1-2 클리어`부터 이어집니다. 새 계정은 1-2 방치 편성·레벨업 안내를 추가로 거치며, 1-3 이후 방치 클리어 미션은 만들지 않습니다. 미션을 누르면 대상 도전을 바로 시작하며 완료된 미션을 누르면 한 번 보상을 받고 다음 미션으로 넘어갑니다.
- 방치 완료·실패는 전장 중앙의 작은 정보성 결과창에 스테이지·생존 시간, 해당 측정 동안 실제 생산으로 획득한 도토리·다이아, 이번 생산 기록을 표시합니다. 실제 지급량과 생산 기록을 별도 영역으로 구분하고 생산 기록은 즉시 지급되는 보상이 아니라고 안내합니다. 최고 기록 갱신 때 기존 최고와 새 기록의 시간당 도토리를 비교하고, 갱신되지 않으면 기존 최고 유지로 표시합니다. 기록별 측정 기간을 사용하며 기간이 없는 이전 기록은 120초로 비교합니다. 첫 측정 전에는 생산 기록이 없어 획득량이 0일 수 있습니다. 전장 전체를 가리거나 전투를 정지하지 않으며, 결과창이 열린 동안에도 3초 뒤 다음 방치가 시작됩니다. 열린 결과창은 다른 결과로 덮어쓰지 않습니다.
- `이 스테이지에서 다시 보지 않기`는 해당 스테이지의 완료·실패 결과창만 숨기고 저장·재접속 후에도 유지합니다. 다른 스테이지에는 영향을 주지 않습니다. 설정의 `방치 결과 → 다시 표시`로 해제합니다. 확인·닫기·Esc로 닫고 스테이지·모드 변경 또는 저장 불러오기·초기화 때 닫습니다.

## 캐릭터

직접 작성한 SVG는 UI 초상화와 Canvas 애니메이션에 같이 사용합니다. 원본은 `dist/src/character-art.js`의 `CHARACTER_ART`이며 비트맵 의존성은 없습니다.

| 디자인 계열 | 공통 몸체·재질·형태 | 동료 |
|---|---|---|
| 야생 | 크림·황갈색 털, 겹친 잎사귀 옷, 목재 무기·방패, 가죽 | 양 방패·속공 토끼·씨앗 다람쥐·등불 여우·폭탄 병아리 |
| 기계 | 청회색 금속 몸체, 황동 테두리, 판금 이음새·리벳, 경첩·렌즈 | 주전자·가시 고슴도치·태엽 부엉이·시계 거북 |
| 정령 | 물빛 몸체, 우윳빛 배색, 유리 같은 반사선, 흐르는 꼬리·지느러미 | 구름·물방울 수달·숲 사슴 기사·별바다 고래 |
| 그림자 | 짙은 보라색, 겹친 망토·뾰족한 끝선, 옅게 빛나는 눈 | 버섯 마녀·눈꽃 펭귄 |

- 계열은 심볼 부착이나 단순 색 교체로 표현하지 않습니다. 기계는 몸체·발·날개까지 금속 구조로, 정령은 몸체와 꼬리를 흐르는 형태로, 그림자는 의복과 외곽을 각진 형태로 만듭니다. 작은 전투 크기에서도 큰 형태와 재질이 읽히도록 하며, 캐릭터의 종·역할을 구분할 실루엣과 소품을 유지합니다.
- 디자인 계열은 동료 자신의 전투 속성으로 저장하지 않습니다. 동료의 `specialties`는 유리하게 상대하는 적 속성이며, 외형 계열과 자동으로 묶어 능력치를 바꾸지 않습니다. 실제 전투 특화는 [전투](battle.md)를 따릅니다.
- 적군은 실외에서 오래 생활해 햇빛에 태닝한 야생 동물이라는 설정입니다. 피부·털은 아군보다 짙은 황갈색·구릿빛·갈색이고, 천은 햇빛에 바랬으며 장비는 마모되었습니다. 색만으로 구별하지 않도록 종·얼굴 무늬·엄니·장비 구조도 다르게 만듭니다.
- 적은 들판 너구리·햇살 토끼·덤불 멧돼지·덩굴 곰·바람 오소리·가시 호저·고철 두더지·빛샘 토끼·그늘 여우입니다. 곰은 큰 앞발·둥근 귀·덩굴 망토와 큰 전투 크기, 오소리는 짙은 얼굴 줄무늬·긴 꼬리·풀잎 허리띠, 호저는 긴 가시·씨앗 주머니로 구별합니다. 야외 생활로 그을린 몸체를 공통으로 두고, 기계는 낡은 판금·고글, 정령은 물결과 유리 반사선, 그림자는 바랜 보라색 망토와 날카로운 눈으로 표현합니다. 야생 동물이라는 설정과 전투 속성 분류는 구분합니다.
- 5·10스테이지 거대 적 4종은 곰·멧돼지의 공격 자세를 공유하되 숲 왕관·나무 어깨 갑옷·큰 엄니·금속 투구·리벳 판금으로 구별합니다. 렌더러는 종별 크기에 거대 적 배율을 곱합니다. 중독은 작은 초록 표식으로 표시합니다.
- 저장·웨이브·전투 계산 호환을 위해 기존 적 ID `beetle`, `mushroom`, `boar`, `clock-beetle`, `shadow-mushroom`은 유지합니다. 이름·설명·그림을 새 설정에 맞췄으며 신규 적은 별도 ID `bear`, `badger`, `porcupine`을 사용합니다. 적 방향은 반전하여 전선 방향이 보이게 합니다.
- 128×120 SVG 좌표 기준 윤곽선 약 3.2px. 점눈, 짧은 입, 작은 소품. 역할별 강한 원색은 사용하지 않습니다.
- 이동할 때만 걷기 동작을 표시하고, 구름은 떠다닙니다. 공격은 종별 준비 자세와 타격/발사 자세, 복귀 동작으로 구분합니다. 피격 시 뒤로 젖혀지는 동작과 짧은 반짝임, 사망 시 사라지는 동작을 표시합니다.
- 씨앗·물방울·번개·포자는 실제 투사체의 위치와 비행 시간을 따라 그립니다. 타격/착탄·회복·대포 효과는 전투 이벤트에서 만들며, 계산 단계를 여러 번 처리하는 프레임에서도 이벤트를 전달합니다. 전투를 새로 시작하면 이전 효과를 지웁니다.
- 애니메이션과 효과는 전투 시간을 따릅니다. 정지와 2×의 규칙, 타격·피격 판정은 [전투](battle.md)의 공격과 피격을 따릅니다.
- 다수 유닛은 작은 깊이 차이로 겹침을 구분합니다. 피격 유닛에만 작은 체력 막대를 표시합니다.

## 모집과 동료 도감

- 첫 안내의 확정 모집도 일반 숲속 배너 모습을 사용합니다. `1회 무료`를 누르면 씨앗 다람쥐가 반드시 나오며, 10회·다른 배너·무료 10회는 첫 안내 중 사용할 수 없습니다. 확정 동료 이름을 모집 전용 창 제목에 쓰지 않습니다.
- 1-2 첫 실패 뒤에도 같은 숲속 배너의 `1회 무료`로 속공 토끼를 확정 공개합니다. 이후 성 추가 피해와 방치에서의 편성 제거를 안내하며 성장창은 1-2 방치 성공 전 잠금 문구를 표시합니다.
- 모집창은 새 동료 초상화와 1회·10회 버튼, 등급 확률·보장까지 남은 횟수, 한 번 무료 10회를 표시합니다. 상세 확률·중복 설명은 확률 메뉴에서 확인합니다.
- 결과는 흰색 카드에 10회 기준 5×2로 표시하며 봉인 카드가 순서대로 공개됩니다. 등급 색·영웅/전설 카드 색감·하단 NEW와 카드 오른쪽 위 징표 심볼·수량으로 결과를 구분합니다. 중복의 징표는 숲 잎사귀·공방 톱니·별빛 별·그늘 달 아이콘으로 표시하고 hover·길게 누르기와 접근성 이름에서 징표 종류/지급량을 확인합니다. 직접 열기·모두 보기·확인·한 번 더를 지원하고 카드 공개 후 누르면 도감으로 이동합니다. 동작 줄이기 설정에서는 공개 지연과 애니메이션을 생략합니다. 지급과 연출의 분리는 [성장·저장](account.md#동료-모집)을 따릅니다.
- 동료 도감은 보유 수/전체 수, 희귀도와 보유 필터를 제공하며 미보유 초상화는 실루엣으로 표시합니다. 상세 화면은 큰 초상화·등급·콘셉트·보유 상태·전투 수치·속성 능력을 보여줍니다.
- 적군 도감 상세에는 속성과 실제 기믹(거대 적·범위 공격·중독·방어막·재생)을 표시합니다. 스탯 이름은 기본 체력·기본 공격력·기본 사거리·기본 이동속도·기본 공격 간격으로 표시하며 배율 관련 부가 설명은 넣지 않습니다. 속성·방어막·회복에 대응하는 아군 이름 목록은 표시하지 않습니다. 효과 이름·수치 설명과 전투 상태 표시는 [공통 효과 정의](characters.md#전투-효과)를 사용합니다. 향후 재충전 배리어·생존 같은 기믹을 구현할 때 해당 효과 설명도 함께 추가합니다. 햇살 토끼의 기본 속성은 야생이며 정령·재생 적은 별도 빛샘 토끼로 표시합니다.
- 신규 동료는 등불 여우·가시 고슴도치·폭탄 병아리·물방울 수달·태엽 부엉이·버섯 마녀·숲 사슴 기사·눈꽃 펭귄·별바다 고래·시계 거북입니다. 원본 게임 그림을 사용하지 않는 SVG 초상화와 전투 스프라이트를 직접 관리합니다. 종별 역할·속성·전투 값은 `characters.js`에서 관리합니다.
- 모집창 상단에서 숲속·공방·별빛 배너를 고르면 대표 동료·대응 색상·등급 확률과 실제 모집 풀이 함께 바뀝니다. 잠긴 배너에는 `2-1에서 열림`을 표시합니다. 모집 공개·다시 모집·확률표는 선택한 배너를 유지합니다.
- 보유 동료는 성장 메뉴에 표시하며, 순서 선택창에는 현재 사용할 수 있는 동료만 표시합니다. 기존 계정의 잠긴 편성에는 `2-1에서 사용`을 표시합니다. 신규 계정은 1-2 방치 첫 실패 뒤 모든 모드에서 10칸 편성을 변경할 수 있으며 선택한 콘텐츠에만 적용합니다. 현재 콘텐츠를 바꾸면 전투를 다시 시작하고 다른 콘텐츠를 바꾸면 현재 전투는 유지합니다.

- 순서 카드는 낮은 높이의 5×2 배열로 표시하고 이동 화살표 버튼을 두지 않습니다. 마우스·손가락·펜으로 카드를 끌어 두 동료 사이에 놓으면 나머지 칸을 밀어 끼워 넣습니다. 빈 칸·중복 동료도 함께 이동하고 교체 버튼은 드래그 대상에서 제외합니다. 카드 초점에서 방향키로도 이동하며 화면 밖 놓기·입력 취소는 초안을 유지합니다. 가로 화면에서 적용 버튼까지 본문 스크롤 없이 표시합니다.
- 순서창의 제목 바로 아래에 `방치 · 도전 · 속공` 선택 버튼을 한 줄로 표시합니다. 진입한 콘텐츠를 기본 선택하며 해당 콘텐츠의 10칸을 편집합니다. 선택 버튼을 바꾸어도 창 안의 편집 초안을 유지하고 `적용`은 현재 선택한 콘텐츠만 저장합니다. 방치 편성 안내에서는 방치를 선택해 엽니다. 수동 전투의 소환 카드·숫자 키와 방치 자동 소환도 해당 콘텐츠 편성을 사용합니다.

## 입력과 실행 상태

- 도전·속공은 소환 카드 또는 키보드 1–9·0으로 소환합니다. 0은 10번째 슬롯이며, 위 행 1–5·아래 행 6–10 순서입니다. Space는 일시 정지, Esc는 모달 한 단계 뒤로 이동하며 첫 화면에서는 닫기입니다.
- 소리는 설정창에서 켜고 끕니다. 방치에는 배속 버튼이 없고 저장된 수동 전투 배속과 무관하게 1×로 진행합니다. 도전·속공 전투에서만 상단 1×/2× 버튼으로 배속을 바꾸며 선택은 저장됩니다. 전체 화면은 설정창에서 제공합니다. 전체 화면 지원 여부는 브라우저에 따릅니다.
- 세로 화면·숨겨진 탭·모달의 전투 정지 규칙은 [전투](battle.md), 저장 파일 이동은 [저장과 복구](../operations/storage-and-hosting.md)를 따릅니다.

## 보석과 접속 복귀

- 메뉴 → 보석은 추가옵션 장착 3칸·보유 종류별 기본 효과, 숲의 보물 모집 배너와 보유 보석 목록을 표시합니다. 개체별 추가옵션을 목록·재료 선택·상세에서 확인합니다. 장착/교체 선택, 강화 재료 선택, 도토리 비용·등급 확률을 명시한 추가옵션 재설정 확인은 공통 모달 종류/크기를 사용합니다. 별도 슬롯 성장·각인 화면은 제공하지 않습니다.
- 순서창의 방치·도전·속공 아래에는 1~10번 동료 편성을 표시하며 보석은 계정 공통 효과로 적용하며 별도 보석 선택은 표시하지 않습니다. 콘텐츠·편성 전환은 초안을 유지하고 적용할 때 선택한 편성만 저장합니다.
- 접속 복귀 후 수익이 있으면 짧은 `자리 비운 동안` 요약 모달에 마지막 접속 시각·부재 시간·정산한 도토리/다이아·8시간 제한 적용을 표시합니다. 확인은 닫기만 하며 방치 계산은 계속됩니다. 다른 안내가 열린 경우 해당 안내를 닫은 뒤 표시합니다. 실제 정산/저장 경계는 [보석과 복귀 수익](gems.md)을 따릅니다.

## 전투 조작

- 상단 시계·방치 안내·생산 기록은 [전투 모드별 제한 시간](battle.md#모드와-시간)을 따릅니다.
- 수동 전투의 배속 버튼은 1×에서 윤곽 아이콘, 2×에서 검은색으로 채운 아이콘을 표시합니다. 선택 상태는 `aria-pressed`로 제공합니다.
- 상단 순서 버튼은 도감 왼쪽에 두며 하단 버튼은 제거합니다. 도전·속공 중에도 순서와 나가기·일시 정지·배속·메뉴에 접근할 수 있습니다. 메뉴 안에는 설정 하나만 표시합니다. 순서 잠금은 기존 1-2 방치 첫 실패 기준을 유지합니다.
- 나가기는 작은 확인창을 열고 계속하기는 현재 전투를 유지합니다. 확인하면 보상·완료·실패 기록을 만들지 않고 방치로 돌아갑니다. 신규 첫 안내 중에는 같은 안내 전투의 시작 대기 화면으로 돌아가 안내 단계를 유지합니다.
- 동료 목록 위에는 기준 동료 다섯 명과 공유 레벨을 표시하고 빈 기준 칸은 자리만 남깁니다. 기준 동료도 눌러 상세로 이동할 수 있습니다. 도감·성장 카드·상세 스펙은 공유 일반 레벨을 반영합니다.

- 상단 전장 알림은 텍스트만 표시하며 옆의 초록색 점은 사용하지 않습니다.

## 배경음과 효과음

- 설정에서 배경음과 효과음을 각각 켜거나 끄고 0~100% 볼륨을 조절합니다. 기본 배경음 30%·효과음 60%이며 0%는 무음입니다. 온라인에서는 서버 계정 설정, 정적 개발에서는 기기 저장에 보관합니다.
- 첫 클릭·터치·키 입력 이후 재생합니다. 숨긴 탭과 세션 종료에서는 소리를 멈추며 복귀하면 현재 스테이지 곡을 이어 재생합니다. 메뉴·일시 정지에는 배경음을 유지합니다.
- 첫 안내는 Journey, 1지역 일반은 Meadow, 2지역 일반은 Workshop, 각 지역 5·10스테이지는 Boss 곡을 반복합니다. 스테이지별 선택은 `dist/src/audio.js`의 `stageMusic`, 음원은 `dist/assets/music/`에 모읍니다.
- Juhani Junkala의 [Chiptune Adventures](https://opengameart.org/content/4-chiptunes-adventure)는 저자가 CC0으로 배포한 곡입니다. 출처·라이선스·변환 내역은 `dist/assets/music/LICENSE.txt`에 보관합니다. 효과음은 게임에서 합성합니다.
