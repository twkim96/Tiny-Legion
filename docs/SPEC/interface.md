# 화면과 아트

## 화면

- 모바일 가로 화면 우선. 667×375, 844×390, 932×430 및 PC 가로 화면을 목표로 합니다.
- 세로 휴대폰 화면에는 회전 안내를 표시합니다. 전투·생산의 시간 규칙은 [전투](battle.md)를 따릅니다.
- 전장이 게임 화면 전체를 채웁니다. 그 위에 좌측 상단 동료 초상화·재화, 상단 중앙 스테이지·시간·상태, 우측 상단 메뉴 아이콘, 하단 소환 카드·속도·소리·대포를 겹쳐 표시합니다. 별도의 상하단 내비게이션 바는 없습니다.
- 전투·동료·모집·도감·설정 아이콘을 누르면 각각 메뉴창이 열립니다. 전투창에서 방치·도전·속공을 선택하며, 상시 전투 모드 탭은 두지 않습니다. 1-3 완료 전 속공은 잠금 아이콘으로 표시합니다.
- 모바일 가로에서는 화면을 채우고 안전 영역을 고려합니다. PC에서는 같은 전장과 메뉴 구성을 최대 1600px의 16:9 패널로 표시하며, 작은 가로 화면에는 밀도를 줄인 구성을 적용합니다.
- 아이보리 `#faf8ef`, 먹색 `#35372e`, 세이지 `#657950`, 약한 금색과 흙색 포인트. 그림은 제한된 색상과 부드러운 윤곽선을 사용합니다.
- 화면 이름은 방치·도전·속공·동료·모집·도감. 홍보 부제, 설명 카드와 메타 용어를 상시 배치하지 않습니다.
- 수치 설명은 PC hover / 키보드 접근 가능한 도감 / 모바일 500ms 길게 누르기에 배치합니다.
- 모달은 키보드 포커스를 가두고, 닫으면 이전 버튼으로 돌아갑니다. 모든 아이콘 버튼에 접근성 이름을 둡니다.

## 캐릭터

직접 작성한 SVG는 UI 초상화와 Canvas 애니메이션에 같이 사용합니다. 원본은 `dist/src/art.js`의 `figures`이며 비트맵 의존성은 없습니다.

| 동료 | 실루엣과 소품 | 역할 |
|---|---|---|
| 양 방패 | 둥근 흰 털, 세이지 얼굴, 앞의 큰 방패 | 저비용 앞줄 방어 |
| 목검 토끼 | 긴 귀, 짧은 흙색 목도리, 나무 검 | 빠른 접근과 연속 공격 |
| 씨앗 다람쥐 | 큰 말린 꼬리, 씨앗 새총 | 장거리 공격 |
| 주전자 | 둥근 몸통, 손잡이, 주둥이 | 범위 공격 |
| 구름 | 부드러운 구름 외곽, 작은 번개 | 장거리 공격과 근처 동료 회복 |

- 적: 작은 딱정벌레, 납작한 버섯 모자, 둥근 멧돼지. 적 방향을 반전하여 전선 방향이 보이게 합니다.
- 128×120 SVG 좌표 기준 윤곽선 약 3.2px. 점눈, 짧은 입, 작은 소품. 역할별 강한 원색은 사용하지 않습니다.
- 이동할 때만 걷기 동작을 표시하고, 구름은 떠다닙니다. 공격은 종별 준비 자세와 타격/발사 자세, 복귀 동작으로 구분합니다. 피격 시 뒤로 젖혀지는 동작과 짧은 반짝임, 사망 시 사라지는 동작을 표시합니다.
- 씨앗·물방울·번개·포자는 실제 투사체의 위치와 비행 시간을 따라 그립니다. 타격/착탄·회복·대포 효과는 전투 이벤트에서 만들며, 계산 단계를 여러 번 처리하는 프레임에서도 이벤트를 전달합니다. 전투를 새로 시작하면 이전 효과를 지웁니다.
- 애니메이션과 효과는 전투 시간을 따릅니다. 정지와 2×의 규칙, 타격·피격 판정은 [전투](battle.md)의 공격과 피격을 따릅니다.
- 다수 유닛은 작은 깊이 차이로 겹침을 구분합니다. 피격 유닛에만 작은 체력 막대를 표시합니다.

## 입력과 실행 상태

- 도전·속공은 소환 카드 또는 키보드 1–5로 소환합니다. Space는 일시 정지, Esc는 모달 닫기입니다.
- 소리, 1×/2× 속도, 전체 화면을 제공합니다. 전체 화면 지원 여부는 브라우저에 따릅니다.
- 세로 화면·숨겨진 탭·모달의 전투 정지 규칙은 [전투](battle.md), 저장 파일 이동은 [저장과 복구](../operations/storage-and-hosting.md)를 따릅니다.

## 코드와 확인

- `dist/index.html`, `dist/style.css`: 화면 구조, 반응형 배치, 안전 영역.
- `dist/src/main.js`: `openBattleMenu`, `renderBattleMenu`, `openModal`, `closeModal`, `showTooltip`, 키보드/포인터 입력.
- `dist/src/art.js`: `figures`, `portrait`, `icon`.
- `dist/src/renderer.js`: `Renderer`, `consumeEvents`, Canvas 전장·투사체·효과.
- `dist/src/combat-visuals.js`: `sampleUnitPose`, 전투 상태에서 공격·피격·사망 자세 계산.
- `tests/combat-visuals.test.js`: 준비·복귀·경직과 전투 시간 기반 자세 확인. Canvas 호출 검사와 실제 화면 가독성 검증은 구분합니다.
- 위 화면 크기는 목표이며 실제 Android/iOS 수용 검증 완료를 뜻하지 않습니다. 확인할 항목은 [TODO](../TODO.md)에 있습니다.
