# 화면과 아트

## 화면

- 모바일 가로 화면 우선. 667×375, 844×390, 932×430 및 PC 가로 화면을 목표로 합니다.
- 세로 휴대폰 화면에는 회전 안내를 표시합니다. 전투·생산의 시간 규칙은 [전투](battle.md)를 따릅니다.
- 전장이 게임 화면 전체를 채웁니다. 그 위에 좌측 상단 동료 초상화·재화·전투력, 상단 중앙 스테이지·시간·상태, 우측 상단 메뉴 아이콘, 하단 소환 카드·속도·소리·대포를 겹쳐 표시합니다. 별도의 상하단 내비게이션 바는 없습니다.
- 전투·동료·모집·도감·설정 아이콘을 누르면 각각 메뉴창이 열립니다. 전투창에서 방치·도전·속공을 선택하며, 상시 전투 모드 탭은 두지 않습니다. 1-3 완료 전 속공은 잠금 아이콘으로 표시합니다.
- 모바일 가로에서는 화면을 채우고 안전 영역을 고려합니다. PC에서는 같은 전장과 메뉴 구성을 최대 1600px의 16:9 패널로 표시하며, 작은 가로 화면에는 밀도를 줄인 구성을 적용합니다.
- 전장 위 재화·스테이지·시간·조작 UI는 테두리 없이 아이콘·초상화·짧은 글자로 표시합니다. 상단 전장에 아래로 사라지는 약한 어두운 그라데이션을 겹치고, 흰색 글자의 크기·굵기로 밝은 맵 위 가독성을 확보합니다. 글자에는 그림자와 외곽선을 사용하지 않습니다. 상단 메뉴는 기존 파스텔 색상과 둥근 사각 아이콘 버튼을 사용하며, 버튼 아래 짧은 이름을 표시합니다.
- 하단 중앙 소환창은 현재 5칸을 한 줄로 나열하며, 카드 줄 자체의 중심을 화면 중앙에 맞춥니다. 흰색 사각 카드와 얇은 먹색 테두리 안에 기존 동료 초상화를 카드 가로·세로 중심에 고정하고, 오른쪽 아래에는 소환 가격을 둡니다. 초상화와 가격이 겹치지 않도록 초상화 크기에 여백을 둡니다. 순서 버튼은 카드 줄 오른쪽 바깥에 둡니다. 이름·설명은 hover·길게 누르기로 확인합니다. 자동 소환 차례는 세이지 테두리, 쿨타임은 어두운 채움과 남은 초, 골드 부족은 흐린 초상화·가격으로 구분합니다.
- 상단 중앙에는 지역·스테이지 번호와 모드·시간을 표시합니다. 계정 재화는 좌측 초상화 옆에 골드·다이아 아이콘과 숫자로 나열합니다. 전투 골드는 오른쪽 아래 대포 위에 별도로 표시합니다. 좌측 상단에는 검 아이콘과 [계정 전투력](account.md#전투력)을 표시합니다. 아군·적 성 체력은 각 성의 깃발 바로 위 중앙에 남은 체력 / 최대 체력과 막대로 표시하며, 전장 크기가 바뀌면 성 좌표에 맞춰 이동합니다. 방치의 1–3 웨이브 표시는 상단 중앙에 둡니다. 전투 골드 막대도 유지합니다.
- 메뉴창은 기존 아이보리·세이지 구성을 사용합니다. 산·전선 배치는 유지하며, 산 뒤 하늘은 차분한 청록색에서 연한 녹색으로 이어지는 그라데이션을 사용합니다.
- 화면 이름은 방치·도전·속공·동료·모집·도감. 홍보 부제, 설명 카드와 메타 용어를 상시 배치하지 않습니다.
- 수치 설명은 PC hover / 키보드 접근 가능한 도감 / 모바일 500ms 길게 누르기에 배치합니다.
- 동료 소환 카드의 hover·길게 누르기와 도감 상세에서 속성 특화, 역할별 보너스, 특수 효과를 설명합니다. 일반 동료는 속성 보너스와 불이익이 없고, 특화 동료도 지정 속성 밖에서는 페널티가 없습니다. 방어 보너스는 표시 체력 증가가 아닌 유효 체력으로 설명합니다.
- 적 도감 상세에는 속성, 방어막·재생 효과, 해당 속성 특화와 방어막 피해 증가·회복 억제를 제공하는 동료를 표시합니다. 방어막 오라는 범위 안 동료의 방어막 대상 피해를 높이는 효과로 설명합니다.
- 스테이지 선택 카드의 정보 버튼을 누르면 웨이브의 적 무리 수를 기준으로 속성 비율을 계산하고, 각 적 무리의 속성·방어막·재생 효과를 초반 0–40초, 중반 40–80초, 후반 80–120초로 나누어 표시합니다. 웨이브 그룹의 속성·방어막·재생 지정은 적 기본값을 대체하며, `shield: false`·`regeneration: false`는 해당 효과를 끕니다.
- 전장에서는 방어막이 남은 적에게 얇은 방어막 윤곽과 방어막 체력 막대를 표시합니다. 재생·둔화·재생 억제는 작은 상태 표식으로 구분합니다. 적 변형은 고유 ID의 그림을 먼저 사용하고, `artId`의 기본 자세와 크기를 이어 사용합니다.
- 모달은 키보드 포커스를 가두고, 닫으면 이전 버튼으로 돌아갑니다. 모든 아이콘 버튼에 접근성 이름을 둡니다.

## 캐릭터

직접 작성한 SVG는 UI 초상화와 Canvas 애니메이션에 같이 사용합니다. 원본은 `dist/src/character-art.js`의 `CHARACTER_ART`이며 비트맵 의존성은 없습니다.

| 디자인 계열 | 공통 몸체·재질·형태 | 동료 |
|---|---|---|
| 야생 | 크림·황갈색 털, 겹친 잎사귀 옷, 목재 무기·방패, 가죽 | 양 방패·목검 토끼·씨앗 다람쥐·등불 여우·폭탄 병아리 |
| 기계 | 청회색 금속 몸체, 황동 테두리, 판금 이음새·리벳, 경첩·렌즈 | 주전자·가시 고슴도치·태엽 부엉이·시계 거북 |
| 정령 | 물빛 몸체, 우윳빛 배색, 유리 같은 반사선, 흐르는 꼬리·지느러미 | 구름·물방울 수달·숲 사슴 기사·별바다 고래 |
| 그림자 | 짙은 보라색, 겹친 망토·뾰족한 끝선, 옅게 빛나는 눈 | 버섯 마녀·눈꽃 펭귄 |

- 계열은 심볼 부착이나 단순 색 교체로 표현하지 않습니다. 기계는 몸체·발·날개까지 금속 구조로, 정령은 몸체와 꼬리를 흐르는 형태로, 그림자는 의복과 외곽을 각진 형태로 만듭니다. 작은 전투 크기에서도 큰 형태와 재질이 읽히도록 하며, 캐릭터의 종·역할을 구분할 실루엣과 소품을 유지합니다.
- 디자인 계열은 동료 자신의 전투 속성으로 저장하지 않습니다. 동료의 `specialties`는 유리하게 상대하는 적 속성이며, 외형 계열과 자동으로 묶어 능력치를 바꾸지 않습니다. 실제 전투 특화는 [전투](battle.md)를 따릅니다.
- 적군은 실외에서 오래 생활해 햇빛에 태닝한 야생 동물이라는 설정입니다. 피부·털은 아군보다 짙은 황갈색·구릿빛·갈색이고, 천은 햇빛에 바랬으며 장비는 마모되었습니다. 색만으로 구별하지 않도록 종·얼굴 무늬·엄니·장비 구조도 다르게 만듭니다.
- 적은 들판 너구리·햇살 토끼·덤불 멧돼지·고철 두더지·그늘 여우입니다. 야외 생활로 그을린 몸체를 공통으로 두고, 기계는 낡은 판금·고글, 정령은 물결과 유리 반사선, 그림자는 바랜 보라색 망토와 날카로운 눈으로 표현합니다. 야생 동물이라는 설정과 전투 속성 분류는 구분합니다.
- 저장·웨이브·전투 계산 호환을 위해 기존 적 ID `beetle`, `mushroom`, `boar`, `clock-beetle`, `shadow-mushroom`은 유지합니다. 이름·설명·그림을 새 설정에 맞췄으며 속성·전투 수치는 유지합니다. 적 방향은 반전하여 전선 방향이 보이게 합니다.
- 128×120 SVG 좌표 기준 윤곽선 약 3.2px. 점눈, 짧은 입, 작은 소품. 역할별 강한 원색은 사용하지 않습니다.
- 이동할 때만 걷기 동작을 표시하고, 구름은 떠다닙니다. 공격은 종별 준비 자세와 타격/발사 자세, 복귀 동작으로 구분합니다. 피격 시 뒤로 젖혀지는 동작과 짧은 반짝임, 사망 시 사라지는 동작을 표시합니다.
- 씨앗·물방울·번개·포자는 실제 투사체의 위치와 비행 시간을 따라 그립니다. 타격/착탄·회복·대포 효과는 전투 이벤트에서 만들며, 계산 단계를 여러 번 처리하는 프레임에서도 이벤트를 전달합니다. 전투를 새로 시작하면 이전 효과를 지웁니다.
- 애니메이션과 효과는 전투 시간을 따릅니다. 정지와 2×의 규칙, 타격·피격 판정은 [전투](battle.md)의 공격과 피격을 따릅니다.
- 다수 유닛은 작은 깊이 차이로 겹침을 구분합니다. 피격 유닛에만 작은 체력 막대를 표시합니다.

## 모집과 동료 도감

- 모집창은 새 동료 초상화와 1회·10회 버튼, 등급 확률·보장까지 남은 횟수, 한 번 무료 10회를 표시합니다. 상세 확률·중복 설명은 확률 메뉴에서 확인합니다.
- 결과는 흰색 카드에 10회 기준 5×2로 표시하며 봉인 카드가 순서대로 공개됩니다. 등급 색·영웅/전설 카드 색감·NEW/조각 표기로 결과를 구분합니다. 직접 열기·모두 보기·확인·한 번 더를 지원하고 카드 공개 후 누르면 도감으로 이동합니다. 동작 줄이기 설정에서는 공개 지연과 애니메이션을 생략합니다. 지급과 연출의 분리는 [성장·저장](account.md#동료-모집)을 따릅니다.
- 동료 도감은 보유 수/전체 수, 희귀도와 보유 필터를 제공하며 미보유 초상화는 실루엣으로 표시합니다. 상세 화면은 큰 초상화·등급·콘셉트·보유 상태·전투 수치·속성 능력을 보여줍니다.
- 신규 동료는 등불 여우·가시 고슴도치·폭탄 병아리·물방울 수달·태엽 부엉이·버섯 마녀·숲 사슴 기사·눈꽃 펭귄·별바다 고래·시계 거북입니다. 원본 게임 그림을 사용하지 않는 SVG 초상화와 전투 스프라이트를 직접 관리합니다. 종별 역할·속성·전투 값은 `data.js`에서 관리합니다.
- 보유 동료만 성장 메뉴와 순서 선택창에 표시합니다. 모든 모드에서 5칸 편성을 변경할 수 있으며 적용하면 전투를 다시 시작합니다.

## 입력과 실행 상태

- 도전·속공은 소환 카드 또는 키보드 1–5로 소환합니다. Space는 일시 정지, Esc는 모달 닫기입니다.
- 소리, 1×/2× 속도, 전체 화면을 제공합니다. 전체 화면 지원 여부는 브라우저에 따릅니다.
- 세로 화면·숨겨진 탭·모달의 전투 정지 규칙은 [전투](battle.md), 저장 파일 이동은 [저장과 복구](../operations/storage-and-hosting.md)를 따릅니다.

## 코드와 확인

- `dist/index.html`, `dist/style.css`: 화면 구조, 반응형 배치, 안전 영역.
- `dist/src/main.js`: `openBattleMenu`, `renderBattleMenu`, `openModal`, `closeModal`, `showTooltip`, `unitSpecialtyText`, `getStageComposition`, 도감·스테이지 정보, 키보드/포인터 입력.
- `dist/src/recruitment-ui.js`: `recruitPanel`, `probabilityPanel`, `revealRecruit`, 등급 표시·모집 공개 연출.
- `dist/src/character-art.js`: `CHARACTER_ART`, 계열 공통 재질·캐릭터별 몸체와 태닝한 적군 그림.
- `dist/src/art.js`: `portrait`, `spriteSvg`, `icon`.
- `dist/src/renderer.js`: `Renderer`, `consumeEvents`, `drawStatusMarks`, `artId` 기반 변형 그림·애니메이션, Canvas 전장·투사체·효과.
- `dist/src/combat-visuals.js`: `battlefieldLayout`, 성과 체력 표시의 공통 좌표; `sampleUnitPose`, 전투 상태에서 공격·피격·사망 자세 계산.
- `tests/combat-visuals.test.js`: 준비·복귀·경직과 전투 시간 기반 자세 확인. Canvas 호출 검사와 실제 화면 가독성 검증은 구분합니다.
- 위 화면 크기는 목표이며 실제 Android/iOS 수용 검증 완료를 뜻하지 않습니다. 확인할 항목은 [TODO](../TODO.md)에 있습니다.
