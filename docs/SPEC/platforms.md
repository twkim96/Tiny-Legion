# 플랫폼 방향

## 확정한 개발 기준

주력 개발은 웹+Android입니다. 게임 계산·공통 데이터·Canvas 전장·HTML/CSS UI는 `dist/`의 한 소스로 유지하고 Android는 Capacitor로 패키징합니다. UI·플레이 규칙 수정은 공통 소스에 반영하며 Android 생성 복사본을 직접 고치지 않습니다. 네이티브 파일 저장·뒤로가기·앱 활성 상태는 Android 연결 계층이 맡습니다.

외부에서 진행하는 수용 테스트의 기준은 기존 [Sites 웹](https://tiny-legion.space-9004.chatgpt.site)입니다. Android는 같은 게임 소스를 사용하는 별도 QA 앱으로 비교합니다. GitHub 커밋·Sites 배포·기기 APK 설치는 각각 별도 결과이며 자동으로 서로 갱신되지 않습니다.

| 실행 경로 | 현재 저장·검증 | 목적 |
|---|---|---|
| 기존 Sites 웹 | Worker/D1 서버 계정·서버 시간 정산·전투 입력 재생 | 외부 테스트 기준 |
| 정적 로컬 웹 | 해당 origin의 기기 내 저장·JSON 복구 | 공통 UI·게임 개발 |
| Android QA 앱 | 번들 웹의 기기 내 저장·Android 문서 선택기 | 실제 WebView·네이티브 수명주기 비교 |

Sites 계정과 QA 앱 진행도는 자동 공유하지 않습니다. 온라인 내려받기는 기록 보관용이며 Android/로컬에 옮기는 복원 경로로 사용하지 않습니다. 자세한 계약은 [서버 계정](server-account.md), [계정 저장](account.md#저장-경계), [저장·복구](../operations/storage-and-hosting.md)를 따릅니다.

## 현재 Android 범위

현재는 테스트용 QA 앱을 유지합니다. 출시용 패키지·서명·AAB·Play Store 등록은 이번 범위에 포함하지 않습니다. APK 구성과 설치·실제 기기에서 확인한 범위는 [Android 개발 안내](../development/android.md)가 관리합니다.

백그라운드에서 화면 전투를 계속 실행하는 기능은 제공하지 않습니다. 전투 계산과 소리는 중지하고 복귀 시 기록 기반 생산을 경과 시간으로 정산합니다. Android 서비스로 전투를 계속 실행하는 방식은 현재 설계가 아닙니다. 정지·정산 계약은 [전투](battle.md#모드와-시간)와 [복귀 수익](gems.md#접속-복귀-수익)을 따릅니다.

## Unity 보존

Unity 2D+URP 이식은 비교 시제품으로 보존하고 주력 개발을 중단합니다. 기존 `codex/unity-migration` 브랜치의 소스·프로젝트·빌드를 삭제하거나 웹/Android 공통 구현으로 간주하지 않습니다. 비교용 Sites `/unity/` 경로를 제공하는 배포를 갱신할 때는 기존 Unity 자산 포함 여부도 확인합니다. 보존은 기능 동등성·모바일 UI 수용 완료를 뜻하지 않습니다.

## 다음 설계 단계
