# 동료 상세와 특수능력

## 상세 화면

- 동료 목록의 카드 자체를 누르면 해당 동료의 성장 상세를 엽니다. 목록에는 자세히·초기화 버튼을 두지 않습니다. 일반 레벨 올리기는 목록과 상세에서 제공합니다.
- 왼쪽은 초상화·희귀도·레벨, 현재 체력/공격력/초당 공격력/사거리/이동속도/공격 간격/소환 골드/대기 시간, 특화 대상과 실제 피해 특성, 기본 특수 효과, 적용된 강화입니다. 일반 레벨·이전 특별강화·장착 보석·특수능력을 함께 반영합니다.
- 오른쪽은 계열별 징표 잔액과 강화 목록입니다. 각 항목의 현재/최대 단계, 다음 단계의 고정 증가량, 징표·도토리 가격을 표시하고 재료 부족·완료·잠금 상태에서는 구매할 수 없습니다. 상세는 화면 안 높이로 제한한 공통 collection 모달입니다. 제목·하단 버튼을 고정하고 특수능력 목록은 최대 420px 및 남은 화면 높이 안에서 별도로 스크롤합니다. 스펙·적용 효과가 길면 왼쪽 영역만 스크롤하고 강화 뒤 목록 위치를 유지합니다. 모바일 가로도 두 열이며 좁은 세로 화면은 위아래 영역으로 나눕니다.
- 상세 하단의 일반 레벨 초기화는 [계정 사양](account.md#현재-성장경제)을 따르며 특수능력을 환급하지 않습니다. 적용·취소 뒤 선택한 동료 상세를 유지합니다. 도감은 별도의 정보 화면입니다.

## 징표와 비용

- 신규 동료의 첫 획득에는 징표를 주지 않고 이후 중복부터 일반 2·희귀 5·영웅 12·전설 30개를 지급합니다. 동료의 원래 대표 특화(`specialties[0]`)에 따라 숲의 징표·공방의 징표·별빛의 징표·그늘의 징표를 사용합니다. 특화 없는 양 방패·씨앗 다람쥐는 숲의 징표를 사용합니다. 강화로 특화를 추가해도 재료 계열은 바뀌지 않습니다. 같은 계열 동료는 징표를 공유합니다.
- 강화에는 해당 계열 징표와 계정 도토리를 함께 사용합니다. 구매 가능 여부를 모두 확인한 뒤 두 재료와 선택한 단계만 한 번에 변경합니다. 신규 성장 해금 시점은 [계정](account.md#1-2-안내와-성장-해금)을 따릅니다.
- 반복 강화의 다음 비용은 현재 단계 r에서 징표 `1+r`, 도토리 `120+80r`입니다. 1회 고유 능력과 특화 추가는 각각 징표 24·도토리 3,000입니다. 초기 조정값이며 수급·성장 속도 승인은 TODO에 남깁니다.

| 반복 옵션 | 한 단계 효과 | 최대 단계 |
|---|---|---|
| 체력 | +1% | 10 |
| 공격력 | +1% | 10 |
| 속성 숙련 | 명시된 피해 특성의 각 효과 +1%p | 10 |

- 공통 강화는 체력·공격력이며 피해 특성이 있는 동료에만 속성 숙련을 제공합니다. 양 방패·씨앗 다람쥐에는 속성 숙련·추가 특화를 제공하지 않습니다. 가벼운 발걸음(이동속도 +2%, 5단계)은 속공·전사 역할인 속공 토끼·등불 여우·숲 사슴 기사·눈꽃 펭귄에만 배정합니다. 탱커·원거리·범위·지원 역할에는 제공하지 않습니다.
- 긴 사거리(사거리 +4, 5단계)는 별바다 고래에만 배정합니다. 명시적인 배정과 함께 전설·원거리·소환 골드 900 이상·소환 대기 6초 이상 조건을 모두 만족해야 합니다. 높은 등급이라는 이유만으로 탱커나 다른 동료에게 자동으로 부여하지 않습니다. 선택 강화의 비용은 기존 반복 강화 가격을 따릅니다.

- 증가량은 고정 원본 수치에 가산하며 이전 단계에 복리로 곱하지 않습니다. 체력·공격력은 최대 +10%를 기본값에 적용한 뒤 일반 레벨·보석 배율과 전투의 반올림을 적용합니다. 속성 숙련은 [피해 특성](characters.md#피해-특성)을 따르며 단단함은 유효 체력, 강함은 유효 체력과 추가 피해, 매서움은 추가 피해를 올립니다.

## 동료별 1회 능력

| 동료 | 고유 능력 | 추가 특화 |
|---|---|---|
| 양 방패 | 중독 면역 | 없음 |
| 속공 토끼 | 적 성 추가 피해 +50%p | 기계 |
| 씨앗 다람쥐 | 공격 간격 −0.1초 | 없음 |
| 등불 여우 | 2초마다 최대 체력 1% 회복 | 그림자 |
| 폭탄 병아리 | 폭발 범위 +24 | 기계 |
| 숲 사슴 기사 | 최대 체력 15%의 방어막 | 정령 |
| 주전자 | 방어막 추가 피해 +100% | 야생 |
| 가시 고슴도치 | 중독 면역 | 야생 |
| 태엽 부엉이 | 공격 간격 −0.1초 | 야생 |
| 시계 거북 | 중독 면역 | 정령 |
| 구름 | 둔화 시간 +1초 | 기계 |
| 물방울 수달 | 회복량 +20% | 그림자 |
| 버섯 마녀 | 3초간 초당 공격력 8%의 중독 피해 | 그림자 |
| 눈꽃 펭귄 | 공격 시 2초간 이동속도 20% 감소 | 그림자 |
| 별바다 고래 | 공격 범위 +45 | 야생 |

- 추가 특화는 1-10 완료로 2-1을 연 뒤 동료별로 한 번 구매합니다. 기존 대상을 유지하며 중복 없이 한 속성을 추가하고 해당 피해 특성의 대상 목록도 확장합니다. 전설은 원래 두 특화에 하나를 추가해 세 속성을 커버합니다. 고유 능력 구매와 특화 추가는 각각 별도입니다.

## 전투와 저장

- 전투 시작 때 동료별 강화 단계를 복사합니다. 진행 중 구매는 이후 소환에도 소급 적용하지 않고 다음 전투부터 반영합니다. 방치 생산 기록에는 당시 단계를 저장하며 새 강화를 기존 기록에 합성하지 않습니다.
- 중독은 체력에 피해를 준 타격/투사체에서만 걸립니다. 성과 중독 면역 유닛에는 걸리지 않으며 면역도 직접 공격 피해는 받습니다. 같은 출처의 반복 중독은 새 틱 피해·지속시간으로 교체하며 피해량을 중첩하지 않습니다. 서로 다른 출처와 다음 틱 처리는 [공통 효과 계약](characters.md#전투-효과)을 따릅니다. 발사자 사망 뒤에도 투사체와 걸린 중독은 유지됩니다. 중독의 피해도 일반 속성·방어막 계산을 사용합니다. 가시 호저의 기본 중독은 초당 공격력 4%·3초입니다.
- 버전 1 계정에 `marks`와 동료별 `abilities`를 추가합니다. 없는 계열은 0, 단계는 알려진 옵션의 정수·상한으로 정규화합니다. `marks`가 없는 이전 저장만 남은 조각을 해당 희귀도 지급량으로 변환하고 조각을 비웁니다. 재접속·내보내기/불러오기 시 다시 변환하지 않습니다. 이미 쓴 특별강화 레벨·동료·진행도·생산 기록은 보존합니다.
- 미배정 이동속도/사거리 강화는 적용·구매를 차단하고 저장 정규화 때 제거합니다. 테스트 중 밸런스 변경에 대한 보상 이주는 제공하지 않습니다. 남아 있는 허용 강화·일반 레벨·고유 능력·보유·편성·생산 기록은 유지합니다.
- 이전 조각 기반 특별강화 함수는 호환용으로 남지만 새 UI와 모집에서는 사용하지 않습니다. 이전 투자 레벨은 전투 레벨에 합산하고 상세에 별도 적용 효과로 표시합니다. 일반 레벨 초기화는 징표와 특수능력을 보존합니다.

## 코드와 검증

- `dist/src/characters.js`: 공통/선택 강화와 동료별 고유 능력·추가 특화 정의.
- `dist/src/abilities.js`: 재료·비용·단계 정규화와 선언된 `changes` 적용.
- `dist/src/effects.js`, `combat-effects.js`: [공통 효과 정의·설명·전투 처리](characters.md#전투-효과).
- `dist/src/character-stats.js`: 레벨·보석·전투 능력치 계산.
- `dist/src/account.js`: `upgradeUnitAbility`, `companionStats`, 중복 모집 지급·전투력.
- `dist/src/save-compat.js`: 이전 조각을 징표로 변환하는 임시 호환 처리. 제거 방침은 [개발 안내](../development/local.md#테스트-저장-호환-코드)를 따릅니다.
- `dist/src/companion-ui.js`, `main.js`: 상세 구성·구매·레벨·초기화·목록 복귀.
- `dist/src/engine.js`, `combat-rules.js`: 전투 스냅샷·고유 효과·중독/면역·특화 계산.
- `tests/abilities.test.js`, `recruitment.test.js`, `ui-flow.test.js`: 비용/상한/지급 원자성·이주 1회·실제 전투 효과·발사자 사망·중독 갱신·기록 보존·상세 구매/초기화 흐름. DOM 대역과 엔진 검사는 실제 가로 화면·WebView 수용 검증과 구분합니다.
