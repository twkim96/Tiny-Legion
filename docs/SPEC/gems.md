# 보석과 복귀 수익

## 해금과 가이드

- 2-1 도전을 완료해 2-2가 열리면 보석과 속공을 함께 엽니다. 이전 1-3 해금은 사용하지 않습니다. 이미 보유한 이전 보석·장비·기록은 보존합니다.
- 2-1 미션 보상 뒤 보석 모집/장착 가이드 미션을 제공합니다. 첫 무료 모집은 햇살 보석을 한 번 지급하고 추가옵션은 정상 추첨합니다. 모집은 자동 장착하지 않아 직접 기본 칸에 넣도록 안내합니다. 기존 계정도 한 번 무료 모집할 수 있습니다. 가이드 수령·보상은 [미션](account.md#미션)을 따릅니다.
- 메뉴 → 보석에는 별도 옵션이 없는 기본 장착 칸 세 개와 보석 프리셋 10개를 제공합니다. 각 프리셋에 서로 다른 보석 개체 세 개를 장착합니다. 같은 개체를 다른 프리셋에 재사용할 수 있지만 한 프리셋의 여러 칸에 중복 장착할 수 없습니다. 슬롯 성장·랜덤 각인은 추후 콘텐츠입니다.
- [콘텐츠별 동료 편성](account.md#콘텐츠별-편성)은 사용할 보석 프리셋 번호를 저장합니다. 변경은 다음 전투부터 적용하고 이전 생산 기록에 새 옵션을 합성하지 않습니다.

## 숲의 보물 배너

| 보석 | Lv. 1 주효과 |
|---|---|
| 햇살 | 초당 전투 골드 +10% |
| 주머니 | 전투 골드 최대량 +15% |
| 도토리 | 새 방치 기록의 도토리 +15% |
| 발자국 | 적 유닛 처치 전투 골드 +20% |

- 네 종류를 각각 25%로 모집합니다. 보석 조각 5개 또는 다이아 30으로 1개를 얻고 첫 무료 모집은 별도 한 번입니다. 속공 보상은 기존 일일 보석 조각으로 지급합니다. 배너 확장·보장 정책은 TODO에 남습니다.
- 보석은 `gemItems`의 개별 `{uid,type,level,options}` 개체입니다. 동일한 종류도 옵션을 별도로 보존합니다. 지급 전체를 준비한 뒤 비용·보유·무료 상태를 함께 변경하고 저장하며 잘못된 입력·무작위 결과 생성 실패에는 지급/차감하지 않습니다.
- 추가옵션은 1·2·3줄이 각각 1/3 확률입니다. 각 줄은 옵션 종류를 동일 확률로 뽑고 해당 범위의 정수 %를 동일 확률로 정합니다. 같은 옵션이 최대 세 줄 반복될 수 있으며 옵션의 수치 자체는 강화해도 바뀌지 않습니다.

| 추가옵션 | 한 줄 범위 |
|---|---|
| 공격력·체력·이동속도 | 각각 +1~3% |
| 야생·기계·정령·그림자 상대 공격력 | 각각 +5~10% |
| 야생 상대 유효 체력 | +5~10% |
| 초당 전투 골드·방치 도토리 | 각각 +1~3% |

- 공통 옵션은 세 보석에서 가산해 기본 능력/수급의 배율을 만듭니다. 속성 옵션은 해당 적에게만 적용하며 동료의 원래 특화 대상이 아니어도 유효합니다. 기존 역할 특화·특수능력 보너스에 가산하고 공통 공격/체력 배율과 구분합니다. 성에는 속성 옵션을 적용하지 않습니다. 전투 적용/피해 상한은 [전투](battle.md#속성-특화와-적-기믹)을 따릅니다.
- 보석 해금 후 적 유닛 처치 기본 전투 골드는 18이며 발자국 배율을 곱합니다. 대포·중독 등으로 죽어도 한 번만 지급하고 전투 골드 최대치를 넘지 않습니다. 아군 사망과 성 파괴에는 처치 골드를 주지 않습니다. 해금 전 엔진에는 처치 보상 0을 전달해 초기 튜토리얼을 유지합니다.

## 강화와 전승

- 보석의 시작 단계는 Lv. 1, 최대 Lv. 10입니다. 현재 Lv. L의 다음 강화는 **동일 종류의 Lv. 1 보석 `2^(L-1)`개**(1·2·4·8·…·256개)와 도토리 `300×L²`를 사용합니다. 주효과만 `기본 효과×(1+0.25×(L-1))`로 높이고 추가옵션은 보존합니다. 초기 비용/배율은 실제 성장 속도 승인 전입니다.
- 강화 재료는 플레이어가 개체별 옵션을 보고 직접 선택합니다. 모든 장착 프리셋에 있는 보석·이미 강화한 보석·대상 자신은 재료로 쓸 수 없습니다. 이전 저장의 옵션 없는 보석 잔여 재료는 선택한 개체 수의 부족분을 채우는 데만 사용합니다. 비용/재료를 모두 검증하고 선택 재료와 도토리를 차감한 뒤 대상 단계만 1 올립니다.
- 전승은 원본보다 낮은 단계의 다른 보석에 가능합니다. 종류가 달라도 가능하며 원본의 Lv. L을 목표 단계로 설정합니다. 목표 추가옵션은 유지하고 원본 옵션은 옮기지 않습니다. 기존 목표 단계와 합산하지 않습니다. 비용은 도토리 `500×L`, 원본은 Lv. 2 이상이어야 합니다.
- 전승 확인에 소멸하는 원본·목표 단계·비용을 명시합니다. 확인 후 원본을 삭제하고 모든 장착 프리셋의 원본 참조를 비웁니다. 목표의 장착 위치·옵션은 보존합니다. 재료 부족·동일 개체·없어진 개체·반복 확인·동급 이상 목표에는 차감/삭제하지 않습니다. 이전 생산 기록도 유지합니다.

## 저장 호환

- 버전 1에 `gemItems`, `gemPresets`(10×3 UID/빈 칸), `gemReserves`, `nextGemUid`, `gemWelcomeClaimed`, `gemGuide`를 추가합니다. 동료 편성 번호와 보석 프리셋 연결은 [계정](account.md#콘텐츠별-편성)의 별도 필드입니다.
- `gemItems`가 없는 이전 저장만 용기·온기·풍요 보유 수를 이주합니다. 종류별 개체 1개를 옵션 없는 Lv. 1로 만들고 나머지는 강화용 잔여 재료로 보존합니다. 이전 장착 보석은 보석 프리셋 1의 첫 칸에 유지합니다. 기존 주효과 공격 +10%·체력 +15%·방치 도토리 +15%는 유지하며 새 배너에는 나오지 않습니다. 재저장·불러오기에서 다시 이주하지 않습니다.
- 정상 개체 ID·단계·중복 옵션·장착 참조는 유지하고 손상/중복 ID를 안전하게 정규화합니다. 개체 참조는 알려진 안전한 ID만 허용하고 손상 장착은 비웁니다. 이는 서버 검증이나 저장 파일 조작 방지를 뜻하지 않습니다.
- 새 방치 기록은 선택한 보석 프리셋과 실제 배율을 전투 시작 스냅샷에 고정합니다. 도토리 효과는 새 측정 기록에만 적용합니다. 레거시 `snapshot.gem` 기록은 당시 효과로 유지합니다.

## 접속 복귀 수익

- 시작 시 저장된 `lastSettled`부터 현재 시각까지 기존 선택 스테이지의 기록으로 한 번 정산합니다. 60초 이상 비웠고 도토리나 다이아를 얻었다면 요약 모달을 표시합니다. 최대 8시간의 기존 생산 한도는 유지합니다.
- 마지막 접속 시각은 Seoul 시각으로 표시하고 실제 부재 시간·정산한 두 재화·8시간 제한 적용 여부를 함께 안내합니다. 재화는 모달을 표시하기 전에 반영/저장하며 확인은 닫기만 합니다. 보상 수령 버튼이나 별도 지급을 만들지 않습니다.
- 숨겨진 탭에서는 주기적 생산 정산/저장을 멈추고 복귀 이벤트에서 누적분을 정산합니다. 숨김 직전·페이지 종료 시에는 기존 생산을 정산해 저장합니다. 모달이 열린 동안 방치는 계속 계산하며 다른 안내가 있다면 닫힌 뒤 복귀 요약을 표시합니다. 짧은 재접속·생산 기록 없음·미래 시각에는 보상 모달을 만들지 않습니다.
- 시작/복귀 정산 자체가 지급과 마지막 정산 시각을 함께 갱신하므로 정상 저장 후 다시 접속해 같은 기간을 지급하지 않습니다. 저장 실패·여러 탭 경쟁·기기 시간 조작·실제 WebView 종료 동작의 기존 한계는 [TODO](../TODO.md)에 남습니다.
