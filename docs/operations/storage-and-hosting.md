# 저장·복구와 정적 호스팅

## 기기 내 진행도 보존

- 저장 위치·형식과 실패 동작은 [계정 저장](../SPEC/account.md)의 계약을 따릅니다. 브라우저 저장은 사이트 origin에 속하므로 localhost와 배포 주소가 자동 공유하지 않습니다.
- 설정 → 저장 파일 → 내려받기로 `tiny-legion-save.json`을 내보냅니다. 브라우저 데이터 삭제·주소 변경·기기 이동 전에 보관합니다.
- 대상 브라우저에서 설정 → 불러오기를 선택합니다. 버전 1 JSON과 필수 필드를 검사하며 1,000,000바이트를 넘는 파일은 거절합니다. 확인 창에서 적용하면 현재 진행도를 교체하고 방치 전투를 새로 시작합니다.
- 불러오기 전에 현재 진행도도 별도 파일로 보관합니다. 복구는 보관한 파일을 다시 불러오는 방식이며 자동 병합·서버 복구는 없습니다.
- 저장 접근이 실패하면 내보내기를 사용합니다. 손상 저장을 읽지 못한 뒤의 새 계정은 기존 진행도 복구를 뜻하지 않습니다.

## 호스팅

- 정적 배포 루트는 `dist/`이며 `.openai/hosting.json`의 `static.directory`와 일치합니다. 이 파일은 Sites 프로젝트 식별 설정도 관리하므로 경로를 임의로 옮기지 않습니다.
- 기존 운영 방침은 기획 검증용 Sites 비공개 배포입니다. Sites source helper를 통한 Git 동기화·아카이브 경로를 사용합니다. 현재 저장소에는 별도 배포 스크립트가 없습니다.
- 비공개 접근 로그인은 게임 서버 계정 저장과 별개입니다. 실제 접근·배포 상태는 배포 시 Sites에서 확인해야 하며 문서 초기화로 확인한 상태가 아닙니다.
- 서버 D1·인증·보상 API는 미구현입니다. 인증 경로·스키마·엔드포인트·운영 복구 절차는 구현과 함께 정리할 대상이며 현재 사용할 API로 안내하지 않습니다.
- `dist/style.css`는 Google Fonts의 DM Sans·Noto Sans KR을 불러옵니다. CSS의 대체 글꼴을 사용하므로 네트워크 제한 시 글꼴이 달라질 수 있습니다. 캐릭터 리소스는 직접 관리하는 SVG입니다.

배포는 별도 요청과 당시 접근 설정을 확인하여 실행합니다. 기기별 수용 검증은 [TODO](../TODO.md)에 남깁니다.
