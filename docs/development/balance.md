# 1지역 밸런스 재현

현재 목표는 [전투 사양](../SPEC/battle.md#1지역-무방치-공략-기준), 미션·우편 지급은 [계정 사양](../SPEC/account.md#우편함의-동료-보상)이 담당합니다. 다음 명령은 저장소의 실제 전투·성장·서버 입력 재생을 사용하며 개인 계정이나 DB를 변경하지 않습니다. Node 22에서 실행합니다.

```sh
node scripts/balance-region-one.mjs
node --test tests/balance-region-one.test.js tests/mailbox.test.js
```

## 계산 조건

- 새 계정에서 첫 안내의 정상 지급 함수를 순서대로 호출합니다. 1-1~1-2의 실제 안내 전투 승패는 `early-encounters.test.js`, 온보딩 관련 기존 회귀가 검증합니다. 이후 1-3부터 실제 전투를 모두 실행하고 서버가 같은 소환·대포 입력을 재생해 결과를 확인합니다.
- 생산 기록을 비워 자연 생산·추가 방치 수입을 모두 0으로 둡니다. 일반 무료 10회·유료 모집·영웅 이상·중복 징표 특수능력·보석은 사용하지 않습니다. 서브미션의 동료는 우편 수령 이후에만 사용합니다.
- 매 전투 전에 실제 무료 환급과 레벨업 함수를 호출합니다. 시작 도토리·첫 완료·직전 미션 지급액에서 차감하므로 예산을 임의로 넣거나 앞으로 받을 보상을 먼저 쓸 수 없습니다. 소환에는 별도의 전투 골드·쿨타임·동료 소유권 검사가 그대로 적용됩니다.
- 실행 결과의 `levels`는 **양 방패 / 씨앗 다람쥐 / 속공 토끼 / 등불 여우 / 폭탄 병아리** 순서입니다. `cannon`은 첫 대포 시각이며 이후 25초마다 발사합니다. 소환은 `TACTICS` 배열을 1초마다 시도하고 성공하면 다음 칸으로 진행합니다. 실패하면 같은 칸을 기다립니다. 정책과 레벨 값의 유지 위치는 스크립트의 `REFERENCE`, `TACTICS`입니다.

## 경계와 비교

`tests/balance-region-one.test.js`는 수입 0 경로의 예산 보존·수령 순서·서버 재생·늦은 클리어, 같은 예산의 균등 투자와 맞지 않는 소환 정책 실패, 강화 없는 공략 실패·대포 필요성을 검증합니다. 별도 `idleAlternatives`는 이미 깬 스테이지를 새로 측정한 실제 기록으로 8시간 정산하고, 단순한 두 동료 집중 투자 또는 일반 3종 투자로 통과하는 대안을 검증합니다. 환급으로 생산 기록이 사라지는 규칙도 그대로 적용합니다.

24시간 성장 기준 변경 후에도 1~2지역 미션 지급액·초반 가격을 고정하고, 기존 1지역 공략의 각 전투 예산이 동일한지 확인합니다. 서버 재생과 같은 예산의 잘못된 투자/소환 정책 실패를 함께 검사합니다.

이는 선택한 재현 입력의 증거입니다. 모든 연속 입력·레벨 배분을 전수 조사한 최적해나 정확히 두 개만 존재하는 해법의 증명은 아닙니다. 특히 1-5는 대포 시점이 민감하며 실제 터치 지연·적 증원 표시·공략 발견 난이도는 사람이 수용해야 합니다. 실제 재미·입력 여유·다른 투자와 무작위 모집에 따른 난이도는 [TODO](../TODO.md)에 남깁니다.

## 장기 경제 모형

```sh
node scripts/balance-economy.mjs
node --test tests/economy.test.js
```

- `overnight`는 현재 1지역 공략의 실제 계정으로 2-1 도전·미션을 완료하고 방치를 측정한 뒤 실제 `recordIdle`·`accrue`·`growUnit`으로 8시간 수입과 낮은 레벨부터 투자한 결과를 계산합니다. 보석 안내 보상·보석 수입 효과·다른 접속 수입은 제외합니다.
- `projectProgression`은 2-1(전역 11)에서 20-1(전역 191)까지 매일 균등하게 스테이지를 올린다는 입력 가정입니다. 90일 경로와 60일 경로는 같은 최종 스테이지에 서로 다른 속도로 도달합니다. 매일 24시간·성 체력 100%를 가정하며, 3지역 이후 보스 미션을 만났을 때만 일회 지급하고 나머지 미션을 임의로 만들지 않습니다. 12시간 누적 한도 안에서 최소 두 차례 정산해 하루 24시간 생산분을 받는 조건이며, 하루 한 번 접속해 24시간을 한 번에 받는 계산이 아닙니다.
- 현재 실제 콘텐츠는 2지역 20스테이지까지입니다. 미래 적·전투 승패·난이도와 해금 미션·첫 완료 보상·모집/보석 지출을 시뮬레이션한 결과가 아닙니다. 특히 만렙 이전에 20지역을 밀 수 있다는 가정의 타당성은 지역 제작 후 확인해야 합니다. 실제 콘텐츠 해금 보상이 추가되면 지급 공식과 이 계산을 함께 검증합니다.
- 현재 모델의 비교 목표는 하루 24시간 생산의 90일 방치 전용 평균 99~100 미만, 60일의 더 빠른 진행과 스테이지 미션 수령 시 5명 100입니다. 같은 진행 속도에서 미션만 켜면 무조건 30일이 단축된다는 뜻은 아닙니다. 풍요 효과·성 방어 성적·정산 간격·누락된 수령에 따라 기간이 달라집니다.
