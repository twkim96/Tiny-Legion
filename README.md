# Tiny Legion

모바일 가로 화면을 기준으로 한 2D 방치·도전·속공 게임의 초기 플레이 버전입니다. PC도 같은 가로 전장과 조작 구성을 사용합니다.

## 실행

Node.js 22 이상과 Python 3이 필요합니다. 런타임 의존성 설치와 빌드 단계는 없습니다.

```sh
npm run dev
# http://127.0.0.1:4173
npm test
npm run check
```

배포 파일은 `dist/`입니다. Sites의 비공개 정적 사이트로 배포합니다. 사이트 ID와 배포 경로는 `.openai/hosting.json`에서 유지합니다. Sites source helper가 Git 동기화와 아카이브를 담당합니다.

## 현재 범위

- 오리지널 동료 5종, 적 3종, 초원 10스테이지.
- 120초 방치, 골드 우선 검사 순환 소환, 순서 변경과 동료 중복 등록.
- 수동 소환 도전, 첫 완료 보상, 진행도에 따른 스테이지 해금.
- 1-3 완료 이후 일일 속공과 보석 1슬롯. 속공은 무제한 재도전, 수동 1회 수령, 수령 후 연습.
- 레벨업, 모집 조각 3개로 특별강화, 일반 레벨 무료 초기화와 골드 전액 환급.
- 검증한 방치 기록의 고정 수익, 다른 전투 중 생산, 최대 8시간 기기 내 오프라인 정산.
- 도감, PC 툴팁, 모바일 길게 누르기, 소리·속도·전체 화면, 저장 파일 내보내기와 불러오기.

**현재 진행도와 재화는 브라우저에 저장됩니다.** Sites 접근 로그인과 게임 계정 저장은 별개입니다. 서버 계정·보상 검증·기기 간 자동 동기화는 아직 구현하지 않았습니다. 기기 시간 또는 저장 파일 조작을 방어하지 않으며 실제 결제와 경쟁 순위에 사용하면 안 됩니다.

## 구조

- `dist/src/data.js`: 동료·적·웨이브 데이터.
- `dist/src/engine.js`: 화면과 독립된 결정적 전투 계산.
- `dist/src/account.js`: 육성, 재화, 기록과 저장 규칙.
- `dist/src/art.js`, `renderer.js`: 직접 제작한 SVG 마스코트, Canvas 전장과 애니메이션.
- `dist/src/main.js`, `dist/style.css`: UI와 입력.
- `tests/`: 전투와 저장·정산의 동작 검증.
