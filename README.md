# Tiny Legion

모바일 가로 화면을 기준으로 한 오리지널 2D 방치·도전·속공 게임의 초기 플레이 버전입니다. PC도 같은 가로 전장과 조작 구성을 사용합니다. 현재 한 지역 10스테이지와 동료 15종을 제공합니다. 모집으로 새 동료를 얻고, 희귀도·보유 상태를 도감에서 확인할 수 있습니다.

## 실행

Node.js 22 이상과 Python 3이 필요합니다. 런타임 의존성 설치와 빌드 단계는 없습니다.

```sh
npm run dev
# http://127.0.0.1:4173
```

실제 소스와 정적 배포 파일은 `dist/`입니다. 테스트·문법 검사와 구조는 [개발 안내](docs/development/local.md)를 참고합니다.

**진행도와 재화는 현재 브라우저에 저장됩니다.** 서버 계정·보상 검증·기기 간 자동 동기화는 미구현입니다. 기기 이동과 백업에는 설정의 저장 파일 내보내기·불러오기를 사용합니다. Sites 접근 로그인과 게임 계정의 차이 및 신뢰 범위는 [계정 저장 사양](docs/SPEC/account.md)에 있습니다.

전투 개념 참고는 냥코대전쟁, 방치 육성 개념 참고는 메이플키우기입니다. 캐릭터·아트·문구·리소스는 자체 제작합니다.
